# 防腐生长实验设计：大型文件不腐坏的边界条件

> 状态：v1.0（2026-08-29 立项）· 决策人：用户 · 执行：编排者+子代理闭环
> 关联：skill `anti-rot-system`（Appendix B 是本协议的便携版）；观测台账 `.superpowers/sdd/progress.md`

---

## 1. 研究问题

**在 AI 高产出开发模式下，一个文件能否在持续增长（超过 800 行的传统拆分线）的同时不腐化？**

动机：AI 编码代理天然倾向于在既有大文件上追加（而不是新建模块），强制拆分有真实成本（搬运风险、review 负担）。如果存在一套 regime 能让大文件保持健康，"何时必须拆"的边界就值得用证据而非直觉来画。

## 2. 先验知识（2026-08-28/29 观测组建档，作为基线证据）

8 个超线文件的代码层深审（`deep-rot-*.md`）给出初始分界假设：

| 大而不腐的共性 | 腐化的共性 |
|---|---|
| 职责单一 | 多职责混放（厨房水槽） |
| 内容以数据/声明为主（CSS、主题表、协议映射） | 逻辑密集且过程式 |
| 有测试、错误处理风格一致 | 零测试、复制粘贴增长模式 |
| 有人管（近期有清理型 commit） | 休眠回避（没人敢碰 ≠ 健康） |

**待证伪/证实的假设 H1**：满足左侧属性的文件，在全协议 regime 下可以安全越过 800 行；腐化信号会先于行数信号出现（深审判定恶化早于 ceiling 触线）。

## 3. 实验设计

### 3.1 分组

- **对照组**：现有 6 个登记 god-file（css.rs / pages_onboarding.rs / cli theme.rs / memory_db.rs / selectors.rs / lsp/manager.rs）。ceiling 钉死不动，常规观测，不做任何干预。
- **实验组**：1 个文件，按 §4 选拔标准产生，ceiling 按当前行数登记并注明"growth-permitted under protocol"。

### 3.2 实验组的全协议 regime

实验组文件适用以下全部机制（比对照组更严，不是更松）：

1. **触碰必附健康度注记**：任何 diff 触及该文件，judge 审查必须附一句健康度观察（更纠结/持平/更清晰 + 依据）——既有 god-file 观测点纪律的强化版。
2. **深审触发器**（命中任一即触发 Appendix A 量规的代码层深审）：
   - 休眠 ≥30 天
   - 单次 commit 增长 >20%
   - 结构评估与代码层观察矛盾
   - 该文件相关代码出现生产 bug
   - 例行：每 3 个功能波至少一次
3. **波末闸**：`check:rot` 红 = 波次不可收口（Layer 3d）。
4. **增长透明**：每次 ceiling 调整必须是"下调"或"带裁决记录的注册上调"（家规 7 不变——实验组不是法外之地，上调走拍板）。

### 3.3 测量与判据

- 每次深审记录：判定（健康/稳定/腐化中）+ 腐化证据计数 + 当前行数。
- **H1 证实**（实验成功）：连续 3 次深审（或 6 周，先到为准）判定不劣化，且腐化证据计数不随行数增长。
- **H1 证伪**（实验失败但有价值）：任一深审判定"腐化中" → 立即拆分（按既有拆分纪律），并**记录是哪个机制先失效**（健康注记流于形式？触发器太迟？行数本身就是熵源？）——失败模式归因是实验的核心产出。

### 3.4 安全边界

- 实验组文件不得处于安全/信任边界关键路径（路径围栏、keyring、确认门这类文件永不进组）。
- 实验组出现任何 Critical 级 review finding = 实验立即中止该文件，拆分，记录。
- 实验不豁免任何测试义务（家规 4 等照硬）。

## 4. 实验组文件选拔标准

同时满足（缺一不可）：

| # | 标准 | 理由 |
|---|---|---|
| S1 | **即将自然生长**：下一波功能的主要落点 | 不生长的文件学不到东西 |
| S2 | **当前健康基线**：最近一次代码层审查判定 健康/稳定 | 先天不良的文件不配进组 |
| S3 | **单职责或数据主导** | 先验知识说这是可健康生长的必要条件 |
| S4 | **有可测性**（既有测试或可附测试） | 无测试的生长是盲飞 |
| S5 | **非信任边界** | 实验失败成本可控 |
| S6 | **有明确 owner 波次**（知道谁在接下来一个月会碰它） | 没人管的文件不在 regime 内 |

选拔流程：编排者提名候选（按 S1-S6 逐项举证）→ 登记进 manifest（note 注明实验组）→ 首个触碰波开始计时。
