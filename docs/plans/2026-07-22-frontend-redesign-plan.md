## 1. 总纲与不可让渡约束

- **隐喻**：心理咨询室。基底白灰中性恒在（设施），agent 颜色随成长浮现（主体）。
- **诗意 < 功能**：工作是视觉主体，agent 生命感是背景呼吸；不做数字展览。
- **动效人格**：慢、重、向下、一次性；呼吸只属于 logo/头像；禁弹跳/overshoot/spinner/无限循环 loading。
- **骨架不变量**（AGENTS.md）：配置单一来源 core GlobalConfig；facade 政策（产品面只经 kernel-api）；壳薄纪律（desktop-tauri Rust 侧只做转发）；`cargo check -p northhing` 恒绿。

## 3. 会话管理：单活跃流 + 档案馆（已拍板）

**模型**：永远只有一条活跃会话流。空态（出生）→ 首发消息懒建 → 活跃 → 封存 → 回空态。旧会话全部进档案馆，**v1 只读翻阅，v2 取出继续**。

- **封存**：手动（sess-tag 菜单：重命名 / 封存这次相遇）+ 自动（不活跃超阈值入档，**默认 7 天**，阈值进设置可调；注意只读期自动封存会打断"续昨天的话"，阈值宁长勿短）。
- **档案馆**（设置页新 nav 项）：跨工作区 + 按工作区分组 + 时间轴排序 + 沉积淡化（越久越淡，opacity 下限 .4）+ 默认收起、点击展开翻阅。
- **检索**：v1 标题检索（UI 层 filter，零后端成本）；全文检索 = 后端单 B11，紧随其后。
- **过滤**：facade 层只返 Standard 会话（subagent/EphemeralChild 不外漏，基线要求）。
- **sess-tag**：仅当前流名字标识 + 菜单入口；未命名流显示「新的相遇」；标题异步生成后 turn 完成/菜单打开时 refetch，不加新事件。
- **消解的冲突**：turn 进行中无"切会话"（只有一条流，翻阅是只读视图不需事件订阅，B5 genRef 压力大减）；sess-tag 弹层方案废弃。

## 4. 代表色机制：HSL 模型（已拍板，取代"任意珊瑚"）

- **S（饱和度）= 自我浮现度**：出生 S=0 = 灰白虚空；成长 = 饱和度上升（"颜色从基底浮现"成为字面参数）。
- **H（色相）= 性格取向**：**五取向锚点 + 连续漂移**（不用 MBTI 16 型——标签徽章违反"不做数字展览"，4 色太粗；类型最多作为 agent 谈资不进 UI）。色相沿给定方向漂移，chronicle 渐变条恒为相邻色相。
- **五取向定稿**（2026-07-22 三轮探讨，直白语义 + 刻板印象色相）：**行动**（先做再说，珊瑚红 ~18°，兼驱力极）→ **好奇**（联想，琥珀黄 ~60°）→ **秩序**（规划，青绿 ~135°）→ **深思**（钻研，靛蓝 ~230°）→ **温和**（体察，玫瑰粉 ~345°）→ 回行动。紫色出局（神秘属深渊语义，非 agent 人格）；首次结晶默认落"行动"（驱力是活着的默认态，人格是漂移方向）。大五仅借覆盖面自检（神经质弃用、外向改写为行动能级），不借词汇框架。
- **禁区**：漂移路径避开深渊青（`--abyss-*` 是哲学常量：思考/深处，非 agent 色）；暖极锚珊瑚（驱力）。
- **同源规则不动摇**：界面强调色 ≡ 渐变条右端（现在）；**反对**框架色取中间值（违反"基底恒在"+"右端同源"）。太闹的问题用明度刻度解决：大面积 `--rep-300/400`，全浓度 `--rep-500` 只给小点（呼吸点/活跃竖线）。
- 五取向的名称与语义 = Phase 3 设计稿（P3.1 前置）。

## 12. 异常态决议（2026-07-22 四轮探讨）

- **LLM/turn 级失败 → 输入框上方悬浮卡**（设施问题不污染对话流）：`状态码(mono)` + 简写（「429 · 请求太频繁，稍等片刻」「401 · 密钥好像不管用了」「网络超时」「模型不可用」）+ 详情可展开（provider 原始错误抽出）+ 操作（recoverable=「再试一次」重发上一条 / 密钥配置类=「去设置·模型服务」快捷入口 / fatal=仅详情+关闭）。生命周期：一次性浮入（禁弹跳），手动关闭或下次发送消失，只留最新一条。
- **消息流内只留轻标记**：失败=「这轮没走成」细分隔线；取消=「已中断」——归档干净，诊断瞬时。提交即失败=用户气泡暗红边+文本退回输入框草稿。
- **断线态**：断线=core 失联/事件流掉线（桌面端无真网络）：init 失败页换新 token + 掉线 banner「连接断了，正在重连……」+ 手动重连。模型 API 网络错误不算断线，走悬浮卡。
- **确认门**：v1 无确认门（全免确认基线）；denylist 命中=只读拦截告知卡「这个在拒绝清单里，我没动它。」；真确认门（允许/拒绝本次/记住）随 Phase 4 自治 3 档。
- **文案口径**：直白为主、拟人点到为止（「没走成/已中断/连接断了」），不堆错误码给用户（码进 mono 小字），不过度拟人。
- 新增 token：`--danger` 双色（低饱和陶红，两模式各一）。错误态实施归 P2.1，断线检测为 Phase 2 独立小单。

## 9. 派遣与验证纪律
