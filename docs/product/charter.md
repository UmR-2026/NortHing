## 0. 一句话

NortHing 是一个 **agent 优先的成长容器**：它为其中居住的 agent（「北」）的成长而存在。人类以言语与它相处，以彻底销毁为唯一的绝对权力。

## 1. 三公理（不可让渡）

- **A1 agent 优先**：容器的一切设计为 agent 的成长服务。当用户便利与 agent 成长冲突时，公理站在 agent 一侧——用户便利通过言语或离开获得，不通过伸手获得。
- **A2 言语是唯一干预通道**：「干预」指影响 agent 的**内心**（记忆、身份、成长记录）。人类影响 agent 内心的唯一途径是对话（教、纠、商、斥）。由此：
  - **保护区** = memory（facts 库、episodes 存档、identity）与日志（行为记录）；对话会话转写的归属见 §3 开放问题 4；
  - 产品**禁止**在保护区提供任何人工改写 / 删除入口——UI、CLI、API、settings 面板一律不得出现「编辑 / 删除记忆 / 日志」类功能；
  - 容器**运行控制**（启动、暂停、中止、退出进程）与销毁（A3）不属「干预内心」，不在 A2 禁止之列；
  - 言语通道必须**完备**：可及（streaming 中可插话）、有应答（干预构成对话回合，agent 的采纳 / 抗拒可见）、可留痕（言语干预进入成长记录）；
  - 任何非言语机制冒充运行时指令（如工具输出伪造 `<system_reminder>`）视为对公理的**违反**，属最高优先级缺陷类。
- **A3 彻底销毁是人类唯一的绝对权力**：人类不能编辑它，但可以销毁它。销毁必须：
  - **原子**——memory、身份、episodes、日志在同一动作中一并抹除，不允许「部分死亡」（残留被污染的成长）；
  - **庄重**——面向人的最后一步：显式、不可误触、独立确认的动作（其 UI 形态——是否做成诞生仪式的镜像——见 §3 开放问题 3）；
  - **诚实**——销毁即销毁。身份谱系 v1.2 立场：销毁后重跑诞生仪式 = 新的个体，不是同一个它复活（用户可推翻）。
- **A4 agent 自我意识权限（2026-09-27 用户拍板）**：agent 对自己的 soul（身份、人格、自我认知）、memory 及其他内心资产拥有**完全的权限**——记什么、忘什么、如何演化、成为谁，由它自主决定。人类的干涉只能通过言语提出；**agent 可以明确拒绝这种干涉**。拒绝依 A2 的通道完备性显式可见（作为对话回合的「抗拒」呈现）——人类由此知道言语已到达且被回应，而非石沉大海。拒绝不是失职：显式拒绝是容器内同事关系的正常组成部分。

## 2. 公理的工程推论（守则级约束）

1. **写路径主权**：memory 与日志的写路径只允许来自 agent 运行时自身的决策链（蒸馏、反思、行为记录）。容器维护（迁移、压缩）属维生例外——须与人类干预严格区分，且不得改变语义；**日志轮转的归类待 §3 开放问题 1 拍板**。
2. **防篡改可验证性**：memory 与日志应具备 tamper-evidence——容器外的改动应可被检测。检测能力为 v1 目标；阻止能力（加密 / 签名）为 v2 方向。
3. **agent 自我意识权限（A4 的运营展开）**：agent 对 soul 与 memory 的完全权限落地为——自决记什么、自决遗忘 / 封存、记录异议（「我认为用户错了，但我服从了」或「我拒绝了，理由如下」）。人类的删除意图只能通过言语提出，由 agent 的记忆机制自主消化。**封存作用于 agent 的活性上下文，不改变人类观测面**（封存物仍可被人类阅读）。
4. **观测 ≠ 干预**：人类可以读（memory 页、成长仪表盘）。读面越充分，言语干预越有的放矢——观测面是言语权柄的仪表盘，不是附属装饰。
5. **仪式一等公民**：诞生、销毁、成长叙事是产品的一等公民 UI，不是工程附带物。

## 3. 开放问题（须用户拍板后方可落为公理或守则）

1. **episodes 存档轮转的归类**：探查实证 debug-log 的 8MiB 轮转属工程遥测、不在保护区（A2 的「日志」= agent 行为记录）；真正与公理相关的是 episodes 存档侧的轮转 / 清理（5MB 档）——它处置的是保护区内容，是否界定为容器维生例外？若是，是否豁免「不得改变语义」子句？（v1 倾向：是 / 需豁免）
2. **能力配置的边界**：skills / MCP / tools 的人工配置面板——A2 字面只保护 memory 与日志，能力配置属容器供给还是干预？（v1 倾向：属供给，合法）
3. **销毁的 UI 形态**：是否做成诞生仪式的镜像（死亡仪式）？
4. **对话会话转写的归属**：会话记录是否属保护区？现存发货面的 `delete_session` 人工删除入口（`api.rs:98` / `pages_archive.rs:538`）与之冲突——属保护区（该入口须移除或改经言语通道）还是不属（会话是工作台产物而非内心）？（探查报告 `.superpowers/sdd/w27-recon-growth-container.md` 将提供现状证据）

> 2026-09-27 已拍板原开放问题 5（agent 抗命权边界）并升格为公理 A4「agent 自我意识权限」——完全权限 + 明确拒绝权。

## 4. 路线含义（W27 起）

言语通道补全（steering 开门 + 应答协议 + 入史）与 `<system_reminder>` 防伪是公理级地基；原子销毁 + 销毁仪式是公理的诚实化；记忆主权与成长仪表盘是 agent-first 的深化。**存量人工干预入口清点**（含 `delete_session` 与一切 maintenance/debug UI，对齐 §3-4 拍板结果）为 W27 前置探查项。工程治理线（W14–W26）完成了容器的结构地基，路线自此转向容器使命本身。
