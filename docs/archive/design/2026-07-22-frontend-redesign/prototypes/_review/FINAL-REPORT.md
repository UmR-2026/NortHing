## 5. P0 必修 3 条(影响 9.0 达标线)

> **修完这 3 条,总分可从 8.6 → 9.7**(校准算式预测)。

### P0-1 · 砍 chat-expanded 操控台 7 控件至 2-3 控件(预计 +0.4)

**位置**:`chat-expanded.html:630-669` `.deck-bar`
**问题**:一行塞 ＋ / 思考分段条 / 工作目录 / 模型 / 自治 / spacer / ctx 圆环 = 7 控件在 38px 一行 = VS Code 状态栏。直接违反哲学第 1 戒"拒绝 dashboard 美学"。
**改法**:保留**输入框 + 发送键 + 一个"更多"折叠入口(三点图标)**,其余 5 控件全部沉入右抽屉"身外之物"(`chat-collapsed.html:561` 已定义抽屉)。

### P0-2 · 补 D2 状态机 4 态 demo(预计 +0.4)

**位置**:新建 `state-machine.html` 或在 `chat-collapsed.html` 顶部加 demo 网格
**问题**:JUDGE-CRITERIA.md § 2.2 要求"空闲 → 思考 → 调用工具 → 生成 → (完成|错误|被打断)"状态机。当前只有 5/10,缺 4 态:**错误 / 被打断 / 等待确认门 / 断线**。
**改法**:
- **错误**:`.danger` banner + 工具 chip 红框 + "重试"按钮
- **被打断**:`⏹` SVG 按钮 + 活跃轮叠加灰罩
- **等待确认门**:活跃轮内嵌 `.confirm-gate` 卡片(abyss-500 左竖线 + "允许 / 拒绝"双按钮)
- **断线**:名片状态点变 `--danger` + "网络中断 · 重连中" + 活跃轮 dim 滤镜
- 顺带演示**发送键 4 态**:↑ / ■ / ⏸ / 禁用

### P0-3 · onboarding personality-chip 改纯文字 + 色板职责分离(预计 +0.3)

**位置**:`onboarding.html:261-310` 整体重构
**问题**:5 颗 chip 用 5 种预设色(紫蓝绿珊瑚冷青) = 把 5 种性格预设成 5 种代表色 = 剥夺 agent 自主选色权。直接违反哲学第 3 戒"代表色是 agent 灵魂" + D4 #1 紫蓝渐变。
**改法**:
- personality-chip 改为**圆角矩形文字按钮**(`r-sm 9px`, 纯文字,无色)
- chip 文字"开放 / 尽责 / 外向 / 宜人 / 神经质"
- **代表色不在 onboarding 处选**。完成 personality 后自动引导到 `identity-creator.html` 选 6 套色板之一(README 文档流程,实际未串联)
- 删 `onboarding.html:286-291` 5 个 `data-color` 预设
- 同步删 `onboarding.html:305-309` 的 5 个 selected 描边色

## 9. 整套原型的"两个高点"

**值得保留下来的部分**:
- `theme-system.html` 范式真值:**6 套代表色 + 亮/暗 + 整屋染色**完整可视化,这套系统能被肉眼读懂。

- `empty-state.html`:**居中在场 + FLIP 头像迁移**诗意最浓,符合"咨询室入口"承诺。

**范式真值与档案馆已经给出 9+ 的范本,chat-collapsed/expanded 与 space-view 缺的是把"范本"用到最高频页**。
