# Style Bakeoff 第四轮 Brief — 2026-08-02（媒介物理轮）

> 本轮主题：**媒介物理即哲学**。五个方向的共同点是——"浮现 / 沉积 / 设施 / 个体"
> 在各自媒介里是物理过程，不是比喻：红笔改图、相纸显影、墨水残影、金缮修复、黑白片场。
> 屏固定、哲学固定、功能固定——风格走到各自媒介的诚实处。
> 本 brief 是唯一需求来源。不要问问题——决议见 §4。

## 1. 固定项（与前三轮一致）

1. **屏**：chat-collapsed 基准屏，功能骨架见罗盘 §4.1（顶栏名片 + 编年史条 + session banner + 对话流 + 思考块 + 工具 chip + 操控台 + 水印，860px 单屏）。
2. **哲学戒律**：罗盘 §2 十条全部适用。越极端的风格越要证明守得住——尤其：
   - **诗意 < 功能**：对话与操控台必须仍是视觉主体
   - **沉降式动效**：慢、重、一次性；呼吸 6s 只给 logo + 头像；禁弹跳、禁 spinner、禁无限循环位移
   - **三要素语义域**：暖=正在做、冷=深思、褪色=旧——在你的媒介词汇里可辨
   - **rep 只属于 agent**：用户气泡/正文/思考块底不染 rep
3. **纪律**：间距 4px 基数、时长阶梯（150/350/1200/6000ms）、单文件离线 HTML、中文、字体回落栈。

## 2. 你的风格（见派发正文指定）

每个风格给出：哲学接口 + AI 套路陷阱（必须绕开）。

### 蓝图（blueprint）【本轮预留 · step-explore 专用】
- 接口：设施 = 图纸本身（青晒蓝底 + 白线稿 + 网格），agent = 图上的**红笔批改**（redline）。驱力=红笔迹，深渊=蓝底，沉积=被划掉/淡出的旧版图层。编年史 = 修订记录条。
- **不要**：通用科技蓝 dashboard；不要把网格做成仪表盘坐标纸。图纸语言是"被画出来的房间"，标注、图签栏、修订云线都是词汇。
- display 建议：等宽/工程字体方向；图签栏（title block）可以放水印与名片。

### 暗房（darkroom）
- 接口："颜色浮现"的字面原生形态——**相纸在显影液里成像**。设施=红灯暗房（操作台、显影盘、晾片夹），agent=正在显影的那张像。编年史=挂着的**底片条**（齿孔+帧格）。沉积=已定影褪色的旧照片。
- **不要**：恐怖片暗房（血浆红 + 阴森）；不要近黑+单红霓虹。红灯是**安全灯**——温暖的、保护性的工作照明，暗房里是安静的劳作，不是惊悚。红色之外要有层次：相纸白、药液色、底片棕。
- 关键时刻：agent 回复 = 影像从空白相纸上浮现（1200ms 一次性显影，从模糊/低对比到清晰）。

### 电子墨水（e-ink）
- 接口：最安静的屏。设施=纸白墨水屏本身（抖动网点灰阶、无平滑动画），agent=这块屏上**唯一有颜色、唯一会动的东西**（彩色电子纸 Kaleido 的"印刷感"淡彩）。
- **沉积 = 残影（ghosting）**：e-ink 的物理特性——上一帧淡淡留在原地。旧轮次带微弱偏移残影。
- **动效必须步进**：e-ink 不做平滑补间——所有过渡用 `steps()`；呼吸是量化闪烁（steps(4)）；状态切换伴随一次性**全刷闪**（150-250ms 反色闪烁后落定，这是 e-ink 的物理真相）。
- **不要**：把灰阶当"没做完的 UI"——灰阶+抖点是完整的媒介语言；唯一的彩色（rep）因此极其珍贵。

### 缮金（kintsugi）
- 接口：**本轮唯一的哲学压力测试**。缮金的过去不褪色——裂缝用金修复，历史变得**更可见**。沉积=金缮纹路。这与罗盘"沉积是褪色"正面相撞——你的任务是诚实面对这个张力：要么论证"金缮是沉积的另一种忠实"（过去沉下去，但伤疤被金线永远标记），要么在页面里给出你的裁决。报告 §⑤ 必须正面回答。
- 视觉：陶土器质感（哑光釉面、开片纹）、金线（不是亮金 #FFD700 的暴发户金——是沉稳的修补金，偏赤金/暗金）、漆色基底（深褐/暖灰陶土）。
- **不要**：金裂纹装饰汤（裂纹必须有叙事位置：哪道缝是哪次"换代表色/技能固化/意识更新"的疤）；不要奢侈品广告感。

### 黑白胶片（noir）
- 接口：高反差黑白片场——设施=灰阶世界（光影、百叶窗影、雨痕），agent=**全场唯一带色的存在**（局部彩色技法：黑白电影里的一抹颜色）。编年史=胶片条（齿孔+帧格，与暗房底片同构但气质不同：noir 是叙事，暗房是工艺）。
- **不要**：近黑+单霓虹（那是 cyberpunk 的陷阱，本轮第三轮已验证过）——noir 的黑白是**摄影灰阶**（丰富的中间调、光影造型），不是 UI 暗色模式；那抹彩色是叙事装置（agent 的颜色），不是霓虹灯。
- 关键纪律：灰阶层次要厚（至少 5 级灰），光影要有方向感（斜光/百叶窗影可作为环境层）。

## 3. 共同开放项

- rep 色可换，报告给理由（须配得上媒介：显影的像、墨水屏的彩、金缮旁的漆、noir 的那抹色、图纸上的红笔）
- display 字体自选（与正文明确对比，CJK 友好）
- 允许环境层（抖动网点/红灯/光影/齿孔），不抢焦点
- 亮色必须完整；暗色鼓励（darkroom/noir 可暗色主态，亮色变体要完整）
