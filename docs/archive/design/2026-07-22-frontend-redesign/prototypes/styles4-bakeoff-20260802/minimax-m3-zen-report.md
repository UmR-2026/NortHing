# 枯山水（zen）· 风格报告 — minimax-m3

## ① 主张
白砂铺开一道庭院：耙痕是时间的物理痕迹，agent 是一块被安置的暗色石，缓慢的苔晕是它唯一在生长之物；对话在石与石之间的留白里发生，水的涟漪是向深处探，沉积是被苔覆盖的旧石——不褪色，但沉入背景。

## ② 三要素
- **驱力 = 苔**：agent 暖朱（寺门朱）作"苔的最暖处"，呼吸只给头像苔晕（6s 唯一 infinite），编年史是砂上一道苔走过的轨迹而非抽象色条——生长方向即驱力方向。
- **深渊 = 水**：abyss 冷青作为思考块左缘 + 静态涟漪纹（同心椭圆）——"向深处探"字面化为水滴入池；ctx 圆环用 stroke 模拟"砂上一圈水痕"，不用数字。
- **沉积 = 旧石被苔覆盖**：旧轮次不删只沉（opacity .58 → .42 递深）+ 苔色淡淡渗入左 30% + 一道"苔印"小字（学 会 沉 默 / 降 生）——沉积是覆盖不是抹除。

## ③ rep 处理
**换色**：从 `#C8714C` 珊瑚 → `#B66647` 寺门朱苔（更暗、更收、像寺门锈红）。
**理由**：珊瑚活泛，枯山水要的是"暗下去才能映苔绿"——寺门朱与砂白底、苔绿、深青石构成四色互补，且更暗的 rep 让"agent 是石"的恒常感不被暖色冲淡。decoration 风险因此下降（暖朱只在头像 / 苔痕 / 活跃轮 / 发送键四处）。

## ④ 戒律自检
1. 非 dashboard：ctx 无数字，活跃轮用苔色左缘而非进度条。✓
2. 品牌水印化：NORTHING 朱印 opacity .25 + 篆体"北"印章，主视觉是石与对话。✓
3. rep 只属 agent：用户气泡 raised 砂色，思考块水色，沉积苔色——均不染 rep；无换色控件。✓
4. 空气染色：顶晕 halo-rep + 底冷雾 air-water，苔色光晕在头像扩散。✓
5. 三语义互斥：暖朱 = 苔 / 冷青 = 水 / 暗绿 = 旧苔——三色域清晰。✓
6. 暖灰基底：`#ECE9E0` 砂白，不纯白不纯黑，色温走暖。✓
7. 字体三系：Fraunces display（18px 名片）+ Noto Serif SC 楷体（标题/思考块/水印）+ Noto Sans SC body + JetBrains Mono 元数据。✓
8. 沉降式动效：呼吸 6s 只给头像苔晕 + session 点；无弹跳、无 spinner、砂纹/涟漪/耙痕全静态。✓
9. 诗意<功能：耙纹环境层 pointer-events: none、opacity 55%，对话与操控台是绝对主体。✓
10. 反 AI 味：无 emoji、无毛玻璃、无紫蓝渐变、低圆角（3-8px 砂面切角感）、`＋` `▾` `↑` 为字符非图标。✓

## ⑤ 最大一注
**让"苔痕"完全替代编年史条**。放弃 tokens.css 里的 `linear-gradient(90deg, birth → rep-300 → now)` 标准编年史形态，改用一道"苔从出生走到现在"的物理轨迹：moss-500 阴苔 → moss-300 嫩苔 → rep-300 暖苔 → rep-400 寺门朱 with 模糊 0.4px 模拟苔的自然晕散边缘 + 两块不规则小石（kink 节点）作为历史凝固点。
**风险**：苔痕的视觉强度比色条低，hover/扫描时易被忽略——但与种子一致（耙过的砂砾是恒常，agent 是石与苔；编年史是"走过"，不是"高亮"）。如果设计师抵触，标准色条是 fallback，但语义损失不可逆。
