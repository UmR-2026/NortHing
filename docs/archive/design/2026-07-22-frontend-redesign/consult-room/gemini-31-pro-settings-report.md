# Settings 页面设计报告 (gemini-31-pro)

**系统继承**：完全复用 v3 的 `sub-card` 卡片语法、`containment` 边框与活膜，保留完整的 mind 五色矩阵与 8s 呼吸动画周期。
**三要素映射**：
- 双光学：完美兼容暗/亮主题（亮色下的深饱和冷边界，暗色下的发光光晕）。
- 生物态：膜线以 8s 为周期脉动，光晕回退到屏幕中上区域，维持静态呼吸感。
- mind 五色：通过顶部 Matrix Controller 直接切换 `--mind-base`，覆盖所有的焦点元素。
**戒律自检**：
- 严格遵循「不是管理后台表格」，使用中心对称的双大卡（诊室壳）实现。
- 「它的自我」列中，沉积记忆使用独立的冷深渊色 (`#3F837B`) 且没有使用 mind 色交互，满足「沉积不带当前 rep」。
- 无任何数字仪表盘式统计。全程使用 v3 指定字体栈（Mono / Agent / UI）。
**最大一注**：将原本作为侧边栏的 `.sub-card` 直接拉升为主视窗的平行双轨结构（左右等宽），以物理的“分裂”布局强制隐喻「自我」与「设施」的区别。
**遗憾**：因缺乏代表 agent 实体的心跳锚点（无头像），全局光晕（`#global-aura`）只能悬停于屏幕中上部，其空间跟随感略弱于 v3 主房间。
