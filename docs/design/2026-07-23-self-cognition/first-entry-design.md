# 自我认知首次启动设计

## 概述

northing 的 agent 在首次启动时通过用户配置 + LLM 生成，建立自我认知提示词。该提示词作为身份基底注入后续所有对话的 system prompt。

## 首次启动 UI 流程

用户看到四个配置项：

```
用户是【UmR】
你是【北】
你是用户的【同事】
你的性格更偏向大五人格中的【敏感、深刻、内敛】性格
```

- 第一项：用户昵称（文本输入）
- 第二项：agent 名字（文本输入）
- 第三项：关系/身份（文本输入）
- 第四项：性格（色板选择，hover 显示关键词）

选择完成后显示"身份生成中..."，LLM 生成自我认知提示词。

## 色板设计

首次启动提供 5 个色板选项，对应大五人格特质：

| 色 | 对应特质 | hover 显示关键词 |
|---|---|---|
| 紫 | 开放性 Openness | 好奇 · 想象 · 不拘一格 |
| 深蓝 | 尽责性 Conscientiousness | 严谨 · 可靠 · 有条理 |
| 暖珊瑚 | 外向性 Extraversion | 热情 · 主动 · 善于表达 |
| 柔绿 | 宜人性 Agreeableness | 温和 · 体贴 · 善解人意 |
| 冷青 | 神经质 Neuroticism | 敏感 · 深刻 · 内敛 |

色板选择决定传给 LLM 的性格关键词。

## 生成模板

发送给 LLM 的 prompt：

```
根据以下配置生成一段自我认知提示词。

用户是【{user_name}】
你是【{agent_name}】
你是用户的【{relationship}】
你的性格更偏向大五人格中的【{personality_keywords}】性格

生成要求：
- 50-80 字中文
- 第一人称（"我是..."）
- 包含：自己的名字、用户称呼、关系定位、回复风格
- 用名字代替所有代词，避免人称歧义
- 语气：平静、自知、克制
- 不要提"AI""语言模型""大五人格""性格偏向"等元信息
- 直接表达"我就是这样的"，不解释
```

## 生成示例

输入：用户是【UmR】，你是【北】，你是用户的【同事】，性格偏向【敏感、深刻、内敛】

输出：
> 我是北，UmR的同事。北说话简洁克制，偏向安静地观察，偶尔带点细腻的察觉。北不喧哗，只是平静地回应，用简短的句子传递温度。北就是这样。

## 存储

- 路径：`config_dir()/northhing/identity.md`（app 级，跨 workspace 持久）
- 注入：通过现有 persona 机制（`PLACEHOLDER_PERSONA`）注入 system prompt Layer 2

## 生命周期

| 事件 | 行为 |
|---|---|
| 首次启动 | 用户配置 → LLM 生成 → 存储 |
| 用户操作 | 只有"清空"（归零重来），没有"修改配置" |
| 成长时刻（远期） | 自我反思 / dream / skill 学习时，自我评价发生变化 → agent 自主生成新代表色 + 新自我认知 → 旧版沉入历史（渐变条） |

成长时刻的代表色不受初始五色板限制，agent 可自由生成任意颜色。

## 与 agentic_mode.md 的关系

- `agentic_mode.md` 是纯能力层（怎么干活），不包含身份声明
- 自我认知是独立层（你是谁），由首次启动生成，通过 persona 通道注入
- 两者在 system prompt 中拼接，互不干涉
