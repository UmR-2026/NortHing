# Onboarding 页面设计报告 (gemini-36-flash)

## 1. 系统继承
- 完整复制 v3 双光学与 `--mind-base` 五色派生架构，继承 8s 生物态呼吸时钟。
- 延续 sub-card / station-head 卡片语法与 containment / membrane 边界。

## 2. 三要素映射
- 身份 4 字段：用户/Agent/关系/性格色板（大五）合一渲染于第一章。
- Provider 配置：模型引擎/Base URL/Key 与心跳脉冲测定校验。
- 工作文件夹：物理存根路径与锚定边界呈现于第三章。

## 3. 戒律自检
- 零 Emoji（纯 Unicode 字符）、无 backdrop-filter、阴影仅 v3 同款 --shadow/--lift。
- 见证者侧无 mind 色，去除仪表盘式数字展台，全叙事量纲表达。

## 4. 最大一注
- 确立“色板选择”为人类唯一改色入口；房间从未着色灰色沉寂态，选择后全屋切至 mind 色并唤醒。

## 5. 遗憾
- 为符合 Slint 安全规范，未使用 CSS 复杂 color-mix 派生渐变动画。
