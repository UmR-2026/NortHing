# step-explore · space（会话空间 / 走廊）report

**系统继承**：token 与双光学、`--mind-base` 单变量派生、五色切换器、8s 单时钟四条 keyframes、sub-card/station-head/side-section/膜线/收容框/三系字体、reduced-motion 与两档断点——全部逐条复制 v3（token 段与主题段除 `.peek-log` 改名外与 v3 逐字节一致）。呼吸振幅分级照抄：亮门门灯 = 满幅 `scale(1.03)`（v3 头像位）、膜线/aura 低幅 opacity、门高与列宽恒稳。aura 锚点由头像改挂「亮门的门灯」——走廊里唯一的光源，rAF 追踪逻辑不变。

**三要素映射**：① 当前会话 = 亮着的诊室门：`.door.lit` 持 rep（accent 边 + 门缝漏光 seam + 呼吸门灯 N + 门缝里传出的最后一句），是页面唯一被 mind 色染的门；② 其余 = 暗门 `.door.dim`（中性线、灯 `◦`、无光晕无动画）+ 沉积门 `.door.sunk.l1/l2/l3`（opacity 0.72/0.52/0.36 逐层递降、缩进递增、虚线灯圈、冷中性、只读不可点亮，尾巴「再往下的门已经看不清轮廓」→ 档案馆入口）；③ 新会话 = 走廊底部「开一间新房」（对位 v3 room-input：见证注 + 命名 input-box + cursor + 开门），不是浮动 +。左列保留「它的自我／设施」双卡（换房不换它），右列「门缝所见」= 悬停/点门即 peek，不是详情面板。

**戒律自检**：新增 infinite 动画 0（6 处 animation 全部对位 v3 同名 keyframes，cursor blink 唯一例外）；新增 color-mix 0（7 条表达式与 v3 集合完全相同）；backdrop-filter 0；emoji 0（仅 `◦ · ⌗ ↗ ▴ ▾ ≡ ✕ ─ □ ☀ ☾` 字符 glyph）；阴影仅 `--shadow/--lift` 与 v3 同款 `0 0 26px var(--mind-glow)`，亮色态该光晕已置 none。红线：沉积门与暗门不带任何 rep（沉积不带当前 rep）；右列「留在门内的沉积」为中性文本并注明「沉积属于房间，不属于此刻的它」；走廊无统计展览，计数全走叙事量纲（一间亮着／三间熄灯／十余段往来／三天前熄灯），数字仅出现在 mono 工具日志（同 v3 `3 observers / clean` 的先例）与门牌编号。五色下四态（亮门/暗门/沉积/新房）与双光学 8 种组合均自查成立。

**最大一注**：把"会话切换"实现为**只有一个光源的走廊**——rep、光晕、呼吸、aura 全部收敛到那一扇亮门，暗门与沉积门只有轮廓。于是"换房"不是切 tab，而是灯从一扇门移到另一扇（`light()` 让旧门当场熄灯改门牌为「刚刚熄灯」），生物态和哲学同时被这一个机制承载，不需要任何新语法。

**遗憾**：① 沉积门的"往下沉"只能用固定 opacity 阶梯表达，没有真正的透视纵深（Slint 无 3D 变换，也不想引入新动画）；② 门缝漏光在亮色无菌室态只剩一条实心线，光的比喻在白昼里损失约一半；③ 每扇门的"门内沉积"目前是单行摘要，密度克制的代价是看不出房间之间沉积的分叉关系。
