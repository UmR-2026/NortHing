# Style Bakeoff Brief — 2026-08-02（第二轮）

> 同一个界面，不同的风格语言。对现有方案（暖灰咨询室 + 珊瑚 + 衬线）不满意，
> 本轮要的是**视觉语言的对立诠释**，不是现有范式的微调。
> 本 brief 是唯一需求来源。不要问问题——决议见 §6。

## 1. 本轮与上一轮的区别

上一轮（bakeoff-20260802）：屏自选、风格在现有范式内。四份产出验证了范式内的完成度。
本轮：**屏固定为 chat-collapsed（核心基准屏），风格完全放开**。
问题是：northing 的哲学——设施、浮现、沉积、对等——除了"暖灰咨询室"，还能用什么视觉语言讲？

## 2. 固定项（不可动）

1. **屏**：chat-collapsed 基准屏。必须包含的功能骨架（见罗盘 §4.1）：
   - 顶栏名片：头像 + 名字「知序」+ 在场状态 + 编年史条（出生灰白 → 现在代表色）+ ⚙
   - 对话流：session banner（左折叠 + 右归档）、活跃轮竖线、用户气泡（右对齐）、agent 回复、思考块、工具 chip
   - 操控台：textarea + 发送键 + 附件 + ctx 环（无数字）
   - 左下水印「northing」、860px 收起态单屏
2. **哲学戒律**（罗盘 §2，逐条适用，风格再变也不能破）：
   - 拒绝 dashboard：无统计数字展览
   - 品牌水印化：logo 只角落 0.25，视觉主体是 agent
   - 代表色只属于 agent：用户气泡/正文/思考块底不染 rep
   - 三要素语义：暖=正在做、冷=深思、褪色=旧——你的配色必须保住这三个语义域，具体色值自定
   - 沉降式动效：慢、重、一次性；呼吸（6s）只给 logo + 头像；禁弹跳/spinner/无限循环位移
   - 诗意 < 功能：对话与操控台是主体
3. **纪律**：间距 4px 基数、时长阶梯（150/350/1200/6000ms）、单文件离线 HTML、中文、字体回落栈（不外链）。

## 3. 开放项（尽管大胆）

- **配色**：可以离开暖灰。冷、暗、工业、有机、纸感、荧光……自定。唯一要求：基底是"设施"的（稳定、中性、不抢），rep 是"agent"的（浮现的个体色），语义三色域可辨。
- **质感**：纹理、颗粒、光、雾、纸、金属——随意，但要有根据（说清为什么这个质感属于 northing）。
- **字体**： display 自选（衬线/黑体/宋体/等宽皆可），正文必须可读，CJK 友好。与 display 形成明确对比。
- **氛围元素**：允许少量环境层（雾、尘、光晕、极慢的悬浮），只要不抢工作焦点、不做成装饰展览。
- **微交互**：hover/一次性过渡，做出"房间是活的"的知觉反馈。

## 4. 明确不要（反 AI 味 + 反现方案惯性）

- 不要照抄现方案：暖灰 #F4F3F0 + 珊瑚 #C8714C + Fraunces 衬线 这一套原样搬来 = 本轮失败
- 不要：紫蓝/靛粉渐变、毛玻璃全家桶、均匀圆角卡片阵、近黑底 + 单一霓虹强调色、奶油米色 + 赤陶 + 衬线（即现方案本身）
- 不要：emoji、毛玻璃模糊、spinner、弹跳
- 不要：把页面做成风格炫技展览——它首先是一个工作界面

## 5. 事实设定

- agent 名「知序」，用户「UmR」。当前代表色默认暖珊瑚 #C8714C——如果你的风格有更有说服力的 rep 色，可以换，但要在报告里给出理由（rep 是 agent 的个性色，不是风格配饰）。
- 对话内容自拟，贴合 northing 气质（agent 在帮 UmR 做事，语气是对等同事）。
- 亮色模式必须完整；暗色鼓励。
