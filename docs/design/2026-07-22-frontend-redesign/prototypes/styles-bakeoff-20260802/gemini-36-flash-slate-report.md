# Style Bakeoff Report — gemini-36-flash (slate)

## 1. 风格命名与一句话主张
- **风格名**：`slate`（玄岩与火种）
- **一句话主张**：northing 不是温软惬意的咨询室，而是高密度、冷峻沉稳的基岩设施；Agent 不是柔光灯，而是岩层深处浮现的燃金火种。

## 2. 哲学根据（为什么此质感属于 northing）
- **设施的冰冷与重力**：放弃「暖灰+米色」的家俱惬意感，采用高对比玄岩灰阶（Slate Bedrock）。设施是坚固、中性、不动摇的岩层框架，支撑 Agent 的生长与沉积。
- **浮现的燃金火种**：Agent「知序」的代表色为燃金琥珀（Ember Gold `#D97706` / `#F59E0B`），它并非装饰配饰，而是沉寂硬质设施中浮现的生机与驱力。

## 3. 三色域与 rep 的处理
- **暖 rep** (`#D97706` Ember Amber)：Agent 专有驱力，用于活跃轮左竖线、头像呼吸圈、编年史条当期端、操控台聚焦。
- **冷 abyss** (`#257A74` Fjord Teal)：深渊探查/思考域，用于思考块左边框、完成态工具 Chip 边框、归档 hover。
- **褪色 ash** (`#94A3B8` Weathered Ash)：岁月沉积域，用于编年史起点灰白、折叠与历史沉降轮次。
- **绝染原则**：用户气泡、正文背景、思考块底色均为中性 Slate 阶，坚决绝染 rep 色。

## 4. 逐条戒律自检 (Compass §2)
1. 拒绝 dashboard：无统计数字/健康指标，全域保持工作区专注。
2. 品牌水印化：左下角 `northing` 水印 opacity 0.25，不抢主视觉。
3. 代表色属于 Agent：用户气泡与正文无 rep 染料。
4. 整屋空气染色：顶栏头像背景 520px 径向燃金微光 halo（8%~14% 极低浓度）。
5. 三要素互斥：暖 Amber=驱力/做，冷 Teal=深思考，褪色 Ash=历史沉降。
6. 设施/基底：离开暖灰 `#F4F3F0`，采用 Cool Slate `#E2E6EA` / `#0B0E11` 矿石高密度基调。
7. 字体栈：离线回落栈，以 Tech Sans 为主体，JetBrains Mono 处理元数据，无衬线依赖。
8. 沉降式动效：头像/Logo 6s 缓和呼吸，无 bounce/spinner/位移动画。
9. 诗意 < 功能：对话流与操控台层次分明，高对比易读。
10. 反 AI 味：无毛玻璃、无紫蓝渐变、无 emoji、无卡片浮沉阴影。

## 5. 与现方案的最大分歧点
- **范式颠覆**：从「温软人本咨询室」（暖灰 `#F4F3F0` + 珊瑚 `#C8714C` + Fraunces 衬线）全面转向「冷峻高密设施 + 燃金个体火种」（Slate Graphite + Ember Amber + Clean Tech Typography）。

## 6. 遗憾
- **离线字体**：未外链 WebFont，完全依赖系统安装的 `JetBrains Mono` / `-apple-system` / `PingFang SC`；在极老旧系统上回落效果略降。
