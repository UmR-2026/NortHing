# minimax-m3 · lithic（石室 / Stone Chamber）

## ① 风格命名与一句话主张
- **风格名**：`lithic`（石室）—— 地层横截面里的对话
- **一句话主张**：northing 不是柔光咨询室，是基岩设施；agent 不是灯，是从裂缝里渗上来的赭石。

## ② 为什么这个质感属于 northing（哲学根据）
四戒律 · 石头是它们的天然载体：
- **设施 = 岩床**：石头不动、稳定、承载——"设施"的最直接物质形态
- **涌现 = 裂缝中的暖光**：不是装饰涂上去的，是从内部渗出来的（与现方案的"咨询室晕染"对立）
- **沉积 = 地层**：沉积岩本身就是时间的沉积——"沉积"成为可见的纹理（极淡的三条 strata 线）
- **对等 = 两人坐在同一块石头上**：基底给两人，没有主人

## ③ 三色域与 rep 的处理
- **rep**：从珊瑚 `#C8714C` 换为 **赭石 `#C28340`**——矿物颜料、沉积岩的橙，更暗更土更在地。论证：珊瑚太"热情外向"；赭石是 agent「正在凝固」的暖，呼应涌现/沉积的时间感
- **冷 abyss**：从深渊青 `#3F837B` 换为 **石青 `#4A6666`**——更绿、更矿物、更冷（像石缝积的冷苔）
- **褪色 birth**：旧岩灰 `#9B938A`——可见的"地质旧"
- **绝染**：用户气泡、思考块底、操控台底、正文——全部中性灰阶，rep 只染头像/活跃竖线/工具进行中态/编年史右端

## ⑤ 与现方案的最大分歧点
- **基底的温度**：现 `#F4F3F0` 米白咨询室 → 本 `#E8E3DA` 风化砂岩骨白
- **rep 的语义**：现珊瑚 `#C8714C` 外向热情 → 本赭石 `#C28340` 矿物在地
- **display 的文化**：现 Fraunces（西式衬线、玩 personality）→ 本 Songti SC / Noto Serif SC（CJK 宋体，刻字感）
- **质感的来源**：现纸面 + 暖晕 → 本地层纹（3 条 strata 线）+ 矿物颗粒（avatar 内部 radial）+ 裂缝渗光

## ⑥ 遗憾
- **离线字体**：宋体依赖系统安装 `Songti SC`（macOS）或 `Noto Serif SC`（Linux/Win），极端环境回落 `STSong/SimSun/Georgia`，气质会打折扣——「刻字感」是本方案的关键
- **纹路密度**：三条 strata 线是 `linear-gradient` 实现的，发丝级，浏览器渲染在低 DPR 屏上几乎不可见——这是符合"不抢焦点"的设计选择，也是"氛围元素"的妥协
- **avatar glyph 用「序」**：与现方案重合，未做更激进替换；CJK 单字 + 宋体 = 刻字感是核心，故保留
- **暗色 surface 对比度**：复用现方案的 1.34:1 已知残留问题；提亮会伤深暖黑气质，本轮选择承接
