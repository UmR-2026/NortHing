# northing 原型评审标准 v4

> 权重：D1 哲学内核(40%) ≥ D2 功能性(30%) ≥ D3 美观程度(20%)
> AI 味为扣分项(D4, -10%)
> 目标总分 ≥ 9.0/10

## D1 哲学内核 (40%)

### 1.1 咨询室隐喻
- 基底白灰中性安全，agent 颜色由成长浮现
- 界面氛围安静、克制，不是 dashboard
- 左暖右冷色温分区：左=生命/暖，右=物件/冷

### 1.2 三要素表达
- 驱力(暖珊瑚 rep-500)：行动、当下、温度——活跃轮竖线、发送键、呼吸点
- 深渊(冷青 abyss-500)：深度、未知——思考块左缘、工具图标、ctx 圆环
- 沉积(褪色)：旧轮 opacity 降低，不加位移

### 1.3 品牌与个体分离
- northing logo 仅角落水印（小、半透明 opacity 0.25）
- agent 头像+名片是视觉主体
- 字体分离：Fraunces 品牌字 / Noto Sans SC agent 名

### 1.4 诗意 < 功能
- 工作是视觉主体，agent 内在表达克制
- 无数字展览（"47 turns"等统计数字）
- 焦点落在对话和操控台上

### 1.5 沉降式动效
- 慢、重、向下。呼吸只给 logo + agent 头像
- 禁止弹跳/overshoot/spinner/气泡弹入
- 状态切换一次性过渡，不做无限循环

## D2 功能性 (30%)

### 2.1 功能元素正确表达
- 发送键随状态变形（↑发送 / ■停止 / 禁用）
- ctx 圆环显示已用百分比
- 思考分段条（5 段，3 亮 2 暗）
- 工作目录、模型选择、自治档位
- 附件按钮(＋)

### 2.2 状态机覆盖
- 空闲(在场) → 思考 → 调用工具 → 生成 → (完成|错误|被打断)
- 名片状态与轮内指示绑定
- 错误态、等待确认门、断线态

### 2.3 会话管理
- session banner 在对话流内（左=session ID 可折叠 / 右=归档）
- 折叠后隐藏对话轮次
- 归档后会话进入左抽屉"已归档"和档案馆

### 2.4 把手与抽屉
- 收起态：8px 窄条渗光，无 chevron/label
- 点击把手 → 窗口物理变宽 + 抽屉滑入
- 左抽屉="它的内在"，右抽屉="身外之物"
- 展开态：把手恢复 28px + chevron

### 2.5 交互动效文档
- Slint 映射注释完整
- 动效有 token 标注（duration/easing）
- 交互行为有注释说明

## D3 美观程度 (20%)

### 3.1 间距一致性
- 4px 基数阶梯（s1=4 / s2=8 / s3=12 / s4=16 / s5=24 / s6=32）
- 模块间距、元素间距统一

### 3.2 字体规范
- Fraunces (WONK 1, SOFT 60)：品牌字、拉丁展示
- Noto Sans SC 400：正文（不用 300，Windows 太虚）
- JetBrains Mono：元数据
- 字号三档：fs-sm 10px / fs-md 11.5px / fs-lg 13px

### 3.3 配色和谐
- 基底暖灰阶（不用纯黑/纯白）
- 代表色同源：界面强调色 ≡ 编年史条右端
- 暗色模式对比度：surface vs bg ≥ 2.5:1

### 3.4 圆角阶梯
- r-sm 9px（控件） / r-md 14px（卡片、头像） / r-lg 18px（大卡片） / r-pill 999px（chip）
- 窗口 20px 为全局常量

### 3.5 暗色模式
- 深暖黑 #181612 系（禁纯黑/霓虹）
- 卡片边界清晰可见
- rep/abyss 色在暗底上正确表达

## D4 AI 味扣分 (-10%)

### 扣分项（每项 -1~-2 分，最高扣 10 分）

| 扣分项 | 扣分 | 说明 |
|---|---|---|
| 通用紫蓝渐变 | -2 | AI 常见配色，northing 用暖珊瑚+冷青 |
| 过度对称居中 | -2 | 缺乏层次，像模板生成 |
| 毛玻璃 glassmorphism | -1 | Slint 不支持，且不符合咨询室质感 |
| emoji 代替图标 | -1 | 应用 SVG 线性图标 |
| dashboard 风格 | -2 | 应是咨询室感，不是控制台 |
| 纯黑/纯白底色 | -1 | 应用暖灰阶 |
| 阴影过于均匀 | -1 | 应有层次，drop-shadow 而非 box-shadow |
| 无个性的"干净" | -1 | 过于安全，缺少 northing 特有的沉降气质 |

### 正面项（不算加分，但 D4 不扣分的前提）

- 有沉降感：旧内容褪色沉入，不是堆叠
- 有温度：暖灰基底 + 珊瑚强调，不是冷冰冰
- 有呼吸：logo 和头像有微妙的生命感
- 有克制：装饰不过度，留白有目的

---

## 评分计算

```
总分 = (D1 * 0.4 + D2 * 0.3 + D3 * 0.2) - D4 * 0.1
```

D1/D2/D3 各 0-10 分，D4 为扣分总和（0-10 分）

**达标线：总分 ≥ 9.0**
