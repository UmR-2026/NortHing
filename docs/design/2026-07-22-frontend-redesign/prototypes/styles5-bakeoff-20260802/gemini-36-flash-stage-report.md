# Style Bakeoff 多色验证轮报告 — Stage (剧场灯光)
**模型**: gemini-36-flash | **风格**: stage (剧场灯光)

### ① 一句话主张
设施是哑光暗台与中性暗幕，Agent 的色温是聚光灯投射的滤光纸（Gel）——"人格改变"即是重新打灯，全空间经由余光沉降全域同频。

### ② 三要素诠释
- **驱力 (Drive)**：主光源切入视线的聚光灯束（`--now` Gel 色），标记活跃焦点与聚焦轮次。
- **深渊 (Abyss)**：侧台幕后冷雾（`#3F837B`），思考块与探查沉入深影，与驱力暖光形成光学互补。
- **沉积 (Deposit)**：历史轮次的暗影余温（`#7B7569` 哑灰），如幕布落下载入历史的落尘。

### ③ 五色兼容机制
基底采用绝对中性的哑光暗木与黑暗幕布 (`#14120E`)。大五人格色全部映射为聚光灯滤光纸（Gel），通过 `--now` 单一变量在 CSS 中控制聚光灯束 (`--now-beam`)、名片光环、编年史条右端、活跃轮左竖线与 Deck 发送键。任何色相在深色舞台背景下均属于光学的自然投射，绝不产生视觉冲突。

### ④ 逐条戒律自检
1. **拒绝 Dashboard**：无 API / 47 turns 等数字展览，呈献沉静剧场氛围。
2. **品牌水印化**：`northing` 处于左下角 25% 透明度，主体突出知序名片与名片光环。
3. **代表色灵魂**：用户气泡保持 `#25211B` 哑光黑，绝对不上色；rep 仅属于 agent 探射焦点。
4. **整屋空气染色**：顶部 480px 径向聚光灯束与侧光渲染整屋空气氛围。
5. **三要素互斥**：暖 beam (`--now`) = 驱力；冷青 (`#3F837B`) = 深渊；褪灰 (`#7B7569`) = 沉积。
6. **暖灰/暗灰基底**：暖暗舞台 `#14120E`，无纯黑无纯白。
7. **字体三系**：Title 用 Fraunces，正文 Noto Sans SC，元数据/标度 JetBrains Mono。
8. **沉降式动效**：600ms 一次性 Gel 切光沉降过渡，无弹跳与循环。
9. **诗意 < 功能**：860px chat-collapsed 标准骨架齐备，切换器为实物调光盘。
10. **反 AI 味**：无 emoji、无毛玻璃、无紫蓝渐变、无均匀阴影。

### ⑤ 五色实测
- **紫 (`#8F7AA0` 开放)**：最稳。高贵优雅的剧场冷紫光，在暗台衬托下极具沉思感与诗意。
- **珊瑚 (`#C8714C` 外向)**：极稳。热烈的舞台琥珀暖光，驱动感最强，聚光灯束氛围最自然。
- **深蓝 (`#566E8A` 尽责)**：很稳。如深夜剧场蓝光，冷静而专一，元数据对比度适中。
- **柔绿 (`#85A08E` 宜人)**：平稳。温润的舞台自然光，柔和不刺眼，呈现温情的陪伴感。
- **冷青 (`#3F837B` 神经)**：最勉强。因冷青与深渊 (Abyss) 同色，选择神经质时驱力与深渊探查视觉边界重叠。

### ⑥ 你押的最大一注
将“换主题”具象化为“剧场调光台更换 Color Gel 滤光片”，使人格色切换成为物理空间中打灯仪式的沉浸延续。
