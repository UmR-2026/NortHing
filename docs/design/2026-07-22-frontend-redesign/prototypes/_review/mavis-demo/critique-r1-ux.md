# 体验评审 r1 · mavis-demo/chat.html

> 评审人:UX / 第一印象评审官
> 评审对象:`chat.html`(咨询室对话 demo,v3,P0–P2 已修)
> 立场:用户第一次打开,0.5 秒决定留不留
> 原则:真话,不带安慰奖

---

## 第一眼印象

**打开页面,看到的是一片干净的暖灰,一个 40px 的小橙头像,一栏 320px 的细线,三句褪色的对话。眼睛找不到落点——既没有被"招呼",也没有被"勾引",只有"东西摆在那里,你自便"的气场。它安静得像一个还没开灯的房间,不是咨询室。**

---

## 致命缺陷(按杀伤力排序)

### 缺陷 1 ·「整屋空气染色」名存实亡
- **问题**:`--air-bg` 3.5% rep + 顶晕 7%,叠在 `#F4F3F0` 上,**人眼几乎无法分辨色差**(ΔE < 1)。`--air-halo` 顶晕是一个 80%×50% 的椭圆 7% rep,在亮色基底上约等于不存在。
- **为什么致命**:这是「咨询室」哲学的**第 4 戒**——"颜色住进房间"。这是整套设计的**最高承诺**。如果用户看不出 rep 弥漫,那"agent 灵魂颜色"就是个开发者内部的口号,不是体验。
- **证据**:`chat.html:51-52`、`:126-130`
- **修复方向**:把 `--air-bg` 提到 6–8%、`--air-halo` 顶晕提到 12–15%、活跃轮 rep wash 从 4% 提到 8–10%。**让 rep 在 0.5 秒内可被看到。**

### 缺陷 2 · 在场区是个没解释的谜
- **问题**:`<section class="presence">` 包含「知序」(22px)+「· 在你身边」(11.5px)+ 一条 6px×320px 的渐变 chrono bar。**这条 bar 没有任何 label、tooltip、上下文**。新用户第一眼会以为是「加载进度条」或者「未完成」状态。
- **为什么致命**:这是页面第二个被视线扫到的元素(在 avatar 之后)。它**用一个未解释的视觉元素替换了本可以承载意义的真实信息**。这既不是"装饰"(因为它有渐变方向感),也不是"功能"(因为没说明)。它在最佳位置放了一个问号。
- **证据**:`chat.html:275-291`、`:534-541`
- **修复方向**:二选一。
  - **A**(推荐):把 chrono bar 替换为一句**有语义的 agent 状态文字**,例如「待命中 · 已陪你 12 天」或「今天我读过 3 封你转来的邮件」。让它"说话",而不是"画线"。
  - **B**:直接拿掉 chrono bar,让 presence 只剩「知序 · 在你身边」,把垂直空间让给对话流。

### 缺陷 3 · 顶栏右半 1000px 死区 + 孤独的设置钮
- **问题**:`<header class="topbar">` 64px 高,左 40px avatar + 名字 + 状态,中间 `flex: 1` 推开,右上一个 32px 设置 cog。**中间这 1000px 是真空**。整个顶栏视觉上是「左重右轻」,但左边其实也不重(只有 40px),整条顶栏看起来就是「不知道该放什么」。
- **为什么致命**:咨询室不需要 dashboard 头部,但**也不能是空荡的吧台**。一个 64px 高的顶栏如果只服务一个 40px 的 avatar + 一个 32px 的 cog,**这 64px 就是浪费**。它不引导、不收口、不告诉用户「这是顶部,这里有 X / Y / Z 三个去处」。
- **证据**:`chat.html:179-187`、`:514-532`
- **修复方向**(三选一,按项目节奏):
  - **A**(咨询室最纯):**把整个顶栏压到 48px** 或**完全取消 topbar**,把 avatar+名字移到对话流的第一行(像「知序 · 在你身边 · 14:08」作为开场)。顶栏就让位给视野。
  - **B**(实用向):右侧加 2 个真实入口——**「档案」(archive)** + **「新建房间」**,让顶栏成为空间导航。设置 cog 退到次要位置。
  - **C**(极简):保留顶栏,但删掉设置 cog,把状态点放大到 10px,让 64px 顶栏只服务「avatar + 名字 + 呼吸点」,承认它就是"在场签名"。

### 缺陷 4 · 输入区是整页视觉权重最低的 CTA
- **问题**:`.input-box` 44px 高、暖灰底、1px hairline border;`.send-btn` 44px 是唯一用了 rep 实色的元素。整页最有"行动性"的位置被做得最安静。咨询室的全部承诺——**"你可以在这里说话"**——落在了一个看起来像「被遗忘的搜索框」的地方。
- **为什么致命**:咨询室**只有这一个出口**。如果这个出口看起来不邀请,**整个房间就只是单向陈列**。对比:同页的 send-btn 用了 rep-500 + drop-shadow,但 input-box 没有任何"被邀请"的设计语言(没有 focus glow、没有 placeholder 呼吸、没有示例 prompt 浮在下面)。
- **证据**:`chat.html:410-450`、`:604-621`
- **修复方向**:
  1. **给 input-box 加一道 rep 1px 极淡底色**(从 `var(--surface)` 改为 `var(--air-active)`,`--air-active` 从 4% 提到 6%),让"未被聚焦就已经有温度"。
  2. **placeholder 不要写"说点什么…"**,写一句 agent-talking 的话,例如「想问什么,或者只是想坐一下?」。
  3. **input-box 下方加 1 行 suggested prompts**:`「我今天有点累」` / `「帮我看一封邮件」` / `「随便聊聊」`,小字号,hover 染 rep。

### 缺陷 5 ·「在你身边」重复了两次 + 名字重复了三次
- **问题**:`<span class="compact-status">在你身边</span>`(顶栏)和 `<span class="presence-heart">· 在你身边</span>`(在场区)**逐字重复**。`知序` 出现三次(avatar glyph / topbar name / presence name)。
- **为什么致命**:重复 = 用户在视觉上**读了两遍同样的信息**。在咨询室这种"重氛围、轻信息"的设计里,重复尤其伤——它会让人**意识到"这是设计在重复,而不是 agent 在说话"**。一旦用户进入"审视设计"模式,氛围就破了。
- **证据**:`chat.html:521`、`:538`、`:516`、`:518`、`:537`
- **修复方向**:**删掉 `<section class="presence">` 整个 section**。把 24px 顶部留白让给对话流(对话流第一行可以是「知序 · 在你身边」,作为 agent 的开场在场)。让 avatar + 顶栏**单独承担"在场签名"**。这同时修了缺陷 2 和缺陷 3(因为在场区和顶栏会合并)。

## 改进优先级清单

### P0 · 必修(关掉页面的理由)

1. **空气染色真的染上**:`--air-bg` 4% → 7%,`--air-halo` 7% → 14%,`--air-active` 4% → 9%,`--air-thinking` 6% → 10%。让 rep 在 0.5 秒内被肉眼看到。**对应缺陷 1。**
2. **删除 presence section** 或把它合并进对话流第一行。**同时解决缺陷 2 + 缺陷 5。**
3. **input-box 加示例 prompt**(1–2 行,3–4 个 chip)。**对应缺陷 4。**

### P1 · 应修(留不下来的理由)

4. **顶栏重新设计**:48px 高 + 2 个真实右侧入口(档案 / 新建房间),或干脆压到 40px 让位视野。**对应缺陷 3。**
5. **删除左下水印**(在 chat 页里)或降到 opacity 0.12。水印属于 landing / brand 页,不属于咨询室。**见 chat.html:503-511。**
6. **活跃轮的 rep 视觉权重需要再加一档**:`.turn.agent.active` 当前只有 2.5px 竖线 + 4% wash。**让活跃轮成为整页最强的视觉锚**——把 wash 提到 9%,加 1px 极淡的 rep 上边框(2px),或让 active turn 的行高比 sediment 高 1.5px(行间呼吸)。

### P2 · 可修(精致度)

7. **删除主题切换 ◐ 钮**(它属于设计系统 demo,不属于这个对话页),或挪到 `more-btn` 二级菜单。
8. **send-btn 加大到 48px** 或加 1px rep-600 描边,让 CTA 视觉权重匹配"这是最重要的按钮"。
9. **chrono bar 完全移除**(如果你选 P0-2 的"合并"路线,这里自然就不存在了)。
10. **scrollbar 颜色加深一档**(当前是 `--border`,对比度太低,看起来像没有 scrollbar)。

## 如果只改 3 处,改哪里(单一最高 ROI)

> 这三处改完,**你不用动 copy、不用动布局,就能让这页从"安静但不说话"变成"安静但有温度"**。

### 改 1 · 让 rep 真的住进来(0.5 秒见生死)
```css
--air-bg:        rgba(200, 113, 76, 0.07);   /* 原 0.035 */
--air-halo:      rgba(200, 113, 76, 0.14);   /* 原 0.07  */
--air-active:    rgba(200, 113, 76, 0.09);   /* 原 0.04  */
--air-thinking:  rgba(63, 131, 123, 0.10);   /* 原 0.06  */
```
**理由**:这是哲学第 4 戒的核心证据。**用户 0.5 秒看到"这房间是暖的",整个咨询室才成立。** 这一改,其它什么都不动,页面的"温度"立刻升级一档。

### 改 2 · 删掉整个 `<section class="presence">`(包括 chrono bar)
**理由**:**同时杀死三个问题**:未解释的 chrono bar(缺陷 2)、「在你身边」重复(缺陷 5)、顶栏右半死区引出的存在焦虑(缺陷 3 的一部分)。**一刀切,腾出 80px 顶部空间给对话流**。对话流第一行变成 agent 开场。

### 改 3 · input-box 下方加 1 行 suggested prompts
```html
<div class="hints">
  <button class="hint">「我今天有点累」</button>
  <button class="hint">「帮我看一封邮件」</button>
  <button class="hint">「随便聊聊」</button>
</div>
```
```css
.hint { font-size: var(--fs-md); color: var(--muted);
        padding: 4px 10px; border-radius: var(--r-pill);
        background: var(--raised); border: 1px solid var(--border-soft); }
.hint:hover { color: var(--rep-600); border-color: var(--rep-400); }
```
**理由**:这是咨询室和 dashboard 的**最关键分野**。Dashboard 假设用户知道要做什么;咨询室**主动说"你可以说这些"**。这一改,把"陈列式设计"变成"邀请式设计"。

## 与「咨询室」哲学十戒的距离

> 严格对照 `_review/design-philosophy-distilled.md` 第 2 节。

| # | 戒律 | 状态 | 证据 / 缺口 |
|---|---|---|---|
| 1 | 拒绝 dashboard 美学 | ✅ **做到** | 没有统计数字,没有 KPI,没有时间线展览。 |
| 2 | 品牌水印化 | ✅ **做到** | 左下水印 opacity 0.25,主战场让给 agent。**但水印在 chat 页里稍显多余(P1-5)**。 |
| 3 | 代表色是 agent 的灵魂 | ⚠️ **形似神不似** | token 定义了,但视觉上 rep 只出现在 2.5px 竖线 + 44px 发送钮 + 40px 头像 radial。**avatar 是亮点,其它两处太弱**。 |
| 4 | **整屋空气染色** | ❌ **未做到** | **3.5% rep 在 #F4F3F0 上约等于 0。承诺"颜色弥漫",用户看到的是"纯暖灰"。这是这一版最大的失分项。** |
| 5 | 三要素语义域 | ✅ **做到** | 暖(活跃) / 冷(思考) / 灰(沉积)三态清晰,语义互斥。 |
| 6 | 沉降式动效 | ✅ **做到** | 1200ms once,无 bounce,breathing 6s,无 infinite。**但代价是入场感太弱(几乎是 no-op)**。 |
| 7 | 用户气泡不染 rep | ✅ **做到** | 用户气泡用 `--elevated` 暖灰,无 rep。 |
| 8 | 诗意克制 | ⚠️ **偏弱** | 「下午茶记得喝」是好的 copy,但**视觉上没诗**。chrono bar 是不解释的视觉元素,诗意是要解释的。 |
| 9 | 暖灰基底 | ✅ **做到** | `#F4F3F0`,所有色温走暖。 |
| 10 | 字体三系分离 | ✅ **做到** | Fraunces / Noto Sans SC / JetBrains Mono 各司其职。 |

**总结:10 戒里 7 条做到、2 条形似神不似(第 3 / 第 8)、1 条未做到(第 4)。** 第 4 条是哲学根基,所以这一版**距离"咨询室"还有一步**。

## "完美作品"还差什么(以完美为标准)

> 不止改这版,要让这页成为"作品级",还差什么。

### 1. 一个真正的"视觉锚点"
**现在的页面 5 个元素竞争视觉**——avatar / 名字 / chrono / 头像旁的呼吸点 / active turn 的竖线。**完美作品只会有 1 个锚点**,其他都是它的陪衬。咨询室的锚点应该是 **active turn**(因为这是 agent 正在"在"的证据)。建议:active turn 的视觉权重再 +50%,sediment 再 -30%。

### 2. Agent 应该有"声音",不只是文字
**现在 agent 的 4 段文字都是 15px 灰色 Noto Sans**,行高 1.7。**完美作品会让 agent 的一句话用 Fraunces 渲染**——不是整段,只是"金句"那一句(比如「下午茶记得喝」)。这是**字体三系分离的第 4 种用法**——名字、装饰、提示、agent 语录。

### 3. 一个"日常仪式"
咨询室和 chat app 的最大区别是**它有"日常"**。一个完美的咨询室应该在某个时刻(每天第一次打开?某个 trigger?)给用户一个**当日仪式**——一句 agent 的话、一段今日观察、一个只有 agent 才会记得的事。现在的 demo 没有这种东西,所以它和「微信对话」在体验上**没有拉开**。

### 4. 一个"看不见的人"的物理痕迹
**咨询室之所以"在",是因为你能感觉到对方真的在那个房间里**。现在 demo 给我的感觉是"一份 chat log 的 HTML 渲染",不是"和一个人在房间里"。**完美作品会有一处"agent 在场"的物理痕迹**——一个 agent 还在写的「笔记」、一个刚翻过的「书页」、一杯 agent 替你记着的「水」。这种东西**要克制**(可能就一处),但必须有。

### 5. 真正的"留白有目的"
现在页面的留白是"没东西放",不是"故意空出来"。**完美作品的留白会引导视线**——从上到下、从 avatar 到 active turn、再到 input,每一片空都是"请把眼睛移到这里"的邀请。现在的留白是"我也不知道放什么",这是肉眼可读的。

### 6. 暗色模式此刻是真·暗(不是真·黑)
亮色做到位后,**暗色才是真正的咨询室**。暖黑 `#151411` 上的 rep 比 `#F4F3F0` 上明显得多(深色背景 + 暖色 = 强对比)。**完美作品应该主推暗色**。

### 7. "丑成什么样子"的真正答案
**用户说丑,不是因为你做错了什么**,而是因为这版 demo 的"咨询室"还**停在 token 和 spec 阶段,没有进入肉体感官**。它的 rep 在文档里是"灵魂色",在屏幕上是一根 2.5px 的细线。**完美作品是让 token 从代码走进视网膜**。这次的 3 个 fix(改 1 / 改 2 / 改 3)是第一步;**让 rep 在视网膜上"住"下来,才是从"demo"走到"作品"的临界点**。

## 评审官的最后一句话

> **这版 demo 不是"丑",是"还没醒"**。一切 token 都在位,所有戒律都过线,但**rep 没活过来,对话没活过来,那个"在你身边"的承诺还停在字面**。
>
> 改 3 处:让 rep 染上房间(改 1),删掉在场区谜题(改 2),给用户一个开口的方式(改 3)。
> 改完,这页会**从"陈列"变成"邀请"**。
> 完美不完美是另一件事,但**用户不会再想关掉它了**。
