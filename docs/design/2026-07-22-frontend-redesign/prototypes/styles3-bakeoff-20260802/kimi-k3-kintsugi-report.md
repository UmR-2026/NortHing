# 缮金（kintsugi）· 风格报告 — kimi-k3

## ① 命名与主张
**缮金**。一句话：这只界面是一只被用过的陶碗——裂缝不藏起来，用金描出来，历史因此比崭新时更可见。

## ② 三要素的物理过程
- **驱力** = 窑火：陶火珊瑚（rep）是正在烧的火——活跃轮暖竖线、头像呼吸、进行中 chip 的暖边框，是"此刻正被烧制"的物理态。
- **深渊** = 大漆：漆色（深褐暖黑）是补碗的底漆，向深处探。思考块以漆色左缘+漆雾渐变呈现；完成的工具从暖边框沉入漆边框（驱力沉入深渊的字面过程）。
- **沉积** = 金缮：旧轮次不褪色，而是沉降（opacity .62）+ 陶胎底色压深 + 一道金线裂纹划过气泡，并带刻记（"主裂 1 · 换代表色 · 金缮于此"）。过去沉下去，伤疤被金永远标记。

## ③ 三色域与 rep
- 暖域（驱力）= 陶火珊瑚 `#B4663C`：只给 agent 的当下动作与"现在"结。用户气泡、正文、思考块底均不染 rep。
- 冷域（深渊）= 漆色 `#3A2E24/#5E4B3A`：在暖陶体系里做相对冷极，深思与完成态的归处。
- 沉积域 = 金 `#B98A2E`（赤金/暗金，刻意避开 #FFD700 暴发户金）：金线是"第四色"，不属于三语义域，它标记的是时间不是状态。
- rep 换色理由：亮金不可作 rep（金已分配给"伤疤"语义），陶火珊瑚与陶土、漆、金三色同窑，是缮金工坊里唯一"正在发生"的颜色。

## ④ 戒律自检
1. 非 dashboard：无数字展览，ctx 为无字金环。✓
2. 品牌水印化：NORTHING 左下 opacity .25，主体是名片+对话。✓
3. rep 只属于 agent：用户气泡陶胎灰、思考块漆色，均未染 rep；无换色控件。✓
4. 空气染色：顶晕+整屋 4.5% 陶火雾。✓
5. 三语义互斥：暖=正在做 / 漆=深思 / 金=旧疤，可辨。✓
6. 暖基底：`#E7E0D3` 陶土，不纯白不纯黑。✓
7. 字体三系：Noto Serif SC 代 Fraunces 职（名/标题）＋ Noto Sans SC 400/500 正文 ＋ JetBrains Mono 元数据。✓
8. 沉降动效：呼吸 6s 仅头像+banner 点；金线静态（伤疤不闪烁）；无 spinner 无循环位移。✓
9. 诗意<功能：裂纹层 z-index 压底、pointer-events 无，对话与操控台是主体。✓
10. 反 AI 味：无 emoji 装饰（chip 内 ✓◌ 为字符符号）、无毛玻璃、无紫蓝渐变、开片纹打破均匀。✓

## ⑤ 放大与牺牲 · 沉积张力裁决
**放大**："过去参与塑造现在"。金缮让编年史第一次有了可触摸的物理形态——三道主裂各有名字（换色/技能固化/意识更新），历史不是淡出的背景而是器物强度的一部分。

**裁决**：罗盘说"沉积是褪色"，缮金说"沉积是被标记"。我的裁决——**两者不矛盾，是同一过程的两半**：褪色发生在"活性"上（旧轮次 opacity .62，确实沉下去了，不再争夺注意力）；金线发生在"事实"上（它碎过这件事不褪色，且被命名为历史）。换句话说：**作为功能的过去必须褪色，作为身份的过去必须显形**。缮金不是沉积的反面，是沉积的诚实形态——沉降依旧发生，只是沉降的轨迹被金描了出来。这与 northing"持续成为"同构：成为不是覆盖旧我，是把旧我的裂痕收进器型。

**牺牲**：暗色模式的纯粹性。漆色已深，暗态下金线与陶胎的明度差会被压缩，"金从裂缝里发光"的关键时刻在暗态会打折；亮色变体才是本风格的完整态。

## ⑥ 遗憾
- 金线用 SVG path 手绘，换窗口尺寸不随形变；理想态应锚定在组件边界（编年史、轮次缘）上生成，HTML 原型只能摆拍。
- 开片纹是 repeating gradient 近似，没有真正的釉下开片的随机感。
- 沉积轮只有一条，"多次沉积叠加不同金龄（新金亮、旧金暗）"的层次没展开。

## ⑦ 最大风险
**金裂装饰汤化**。一旦裂纹没有叙事锚点，本风格立刻退化成奢侈品包装。深化第一步：建立"裂缝台账"——每道金线必须可回答"这是哪次事件的疤"（挂编年史数据），UI 上无名之裂一律不画。这条规则应写进 token 层（crack 元素强制 data-event 属性），否则三轮迭代后必然失守。
