# step-explore-blueprint · 风格焙烧第四轮报告（蓝图 / 媒介物理轮）

① **命名与主张**
蓝图（blueprint）——**设施是一张图纸，知序是图上正在落下的那支红笔。**房间不是被"设计"出来的，是被**画**出来的：图框、中心线、剖面、标注都在场，而 agent 唯一的存在方式是审图人的红笔迹。人起稿（铅笔），它批改（红笔）——对等同事的两支笔。

② **三要素在本媒介里的物理过程**
- **驱力 = 红笔迹**。活跃轮外圈一道**修订云线**，由红笔 `stroke-dashoffset` 一次性描出（1200ms），左缘 2px 红竖线自上而下画下来（scaleY 0→1，沉降方向）。笔画完就停在纸上——不循环、不呼吸、不发光。云线按元素实际尺寸生成均匀扇形（JS `cloudPath`），不是贴图变形。
- **深渊 = 蓝底 / 剖面**。向内看 = 把图剖开：思考块是 `A—A 剖面`，45° 剖面线覆盖，底色是青晒蓝本身。它看的是纸的**里面**，而纸的里面就是蓝。暗态整张图退回青晒（普鲁士蓝地 `#0F2A38`）——深渊从元素涨成了整个基底。
- **沉积 = 被取代的旧版图层**。旧轮次晒退（`#8E9599` + opacity .5）+ 版本号 `Δ3` 被一条线**划掉** + 灰蓝「作废」章 + 「此版已被 Δ5 取代 · 旧线保留在图上」。划掉不是删除：旧线还在图上，只是不再生效。纯褪色，零位移，hover 回升 .72。
- **编年史 = 修订记录条**。5 枚 Δ 标记各自留着那一代的颜色（出生灰 → `#A6A794` → `#A98A72` → rep-300 → 现在的红），下面一条 132px 渐变尺。最右一枚 ≡ 界面强调色（同源色绑定）。

③ **三色域与 rep**
- 暖=正在做：**rep 换为工程审图红** `#BC4A38`（暗态 `#D65A44`，hue≈9°，从珊瑚 30° 挪过来）。理由：图纸上第二种墨只能是红笔——珊瑚是涂料，红笔是**权限**，它落哪里哪里正在被改；氧化铁质地（非荧光红），亮态 on `#F4F3F0` 对比 4.5:1。
- 冷=深思：**青晒蓝** `#2F6980`（hue≈197°，罗盘冷青 185° 向普鲁士蓝偏 12°，让"蓝底"与"深渊"是同一种蓝）。用于剖面、完成 chip、ctx 环、归档 hover、右把手、四级线宽的全部线稿。
- 褪色=旧：`#8E9599` 晒退灰蓝 + 划线 + 作废章（**章绝不用红**——红只属于正在做的事）。
- **rep 零外溢**：用户轮是铅笔（石墨 `#6E6A63` + `HB` 笔号标签），正文 fg，思考块底是 abyss 5%，沉积轮是灰蓝。界面无换色控件。

④ **戒律逐条自检**
1 无 dashboard：无数字展览（ctx 环无数字、思考分段无刻度）；`860` 是**图幅尺寸**（图纸自述纸张，随 860↔1280 变化），不是遥测 ✓
2 水印化：northing 独占图签栏首格，opacity .25，与任何元素不重叠；视觉主体是审图章 + 名片 ✓
3 rep 只属 agent：见 ③ ✓
4 整屋染色：底 rep 6.5%（`#F0E9E5`）+ 顶晕锚定审图章（420px 径向）+ 聚焦升 7.5% + 底部 abyss 冷雾 ✓
5 三域互斥：红笔=做 / 蓝底剖面=思 / 晒退划掉=旧，三者在图纸词汇里各有物理位置 ✓
6 暖灰基底：亮态 `#F4F3F0` 原值分毫不动。**暗态是自觉偏离**——brief 指定"深渊=蓝底"，青晒的地就是普鲁士蓝，不可能是 `#181612`；作为交换，亮态（白图）是本风格的主态与完整态 ⚠️（记为设计裁决，交终审）
7 字体三系：display **换 Fraunces 为长仿宋**（GB 工程制图法定字体，图纸上的汉字母语）/ 正文 Noto Sans SC 400 / 元数据 JetBrains Mono；全回落栈、零外链 ✓
8 沉降式：呼吸 6s 仅"透明度"（水印 logo + 审图章墨晕 + 两枚在场点，后者沿用基准原型 chat-collapsed 真值）；云线与竖线均 1200ms 一次性；归档 1200ms 淡出；无弹跳/spinner/无限循环位移；沉积是褪色 ✓
9 诗意<功能：图纸词汇全部 ≤.4 alpha 或退在边距带（图框/纸格/中心线/尺寸线/对中符号），对话与操控台是唯一实心主体 ✓
10 反 AI 味：无 emoji、无毛玻璃、无紫蓝渐变、**全文件零 box-shadow**（图纸上没有投影）、圆角整体降至 3/6/9（图纸的角是画出来的直角，圆角只作倒角级别；记为自觉偏离）、网格无主次刻度无坐标轴（是描图纸纸格，不是仪表盘坐标纸）✓

⑤ **最放大的一面 / 牺牲的一面**
放大：**"过去仍在场但不再生效"**。别的媒介只能让旧的变淡，图纸能让旧的**被划掉却还留在纸上**——沉积第一次同时是"失效"和"可查"，且不需要任何解释文案。附带放大的是"对等同事"：铅笔与红笔是两种笔，不是主客。
牺牲：**亲密与温度**。图纸是审查场景，天然带评判气质——咨询室的"被陪伴"退成了"被复核"。以及安静：图纸是有信息密度的媒介，边距带的图框/标注即使压到 .4 alpha 以下，也比空白墙面吵。

⑥ **遗憾**
修订云线现在只有一朵（活跃轮）。云线本该是**可累积的历史**——每次修订留一朵越来越淡的云，屏上就能读出这张图被改过几轮；受单屏基准限制没做，导致云线目前更像"活跃标记"而不是"修订记录"。另：作废章的角度与位置是手拍的，沉积轮变高时会偏。

⑦ **若深化，下一步最该解决的 1 个风险**
**暗态（青晒）的基底裁决必须先定死**：它是本风格唯一与罗盘戒律 6 正面相撞的地方。要么承认"青晒是蓝图不可让渡的物理态、亮态白图承担暖灰契约"，要么放弃暗态只保留白图。悬着不判，风格扩到 archive/settings/space 五屏后会分裂成两套互不承认的基底，届时返工成本远高于现在拍板。
