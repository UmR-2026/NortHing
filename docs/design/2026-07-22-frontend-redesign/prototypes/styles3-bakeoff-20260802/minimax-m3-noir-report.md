# minimax-m3 · noir（黑白胶片）

## ① 风格命名与一句话主张
- **风格名**：`noir`（黑白胶片 · 黑白的 noir 是摄影灰阶不是 UI 暗色）
- **一句话主张**：northing 是一座高反差黑白片场——设施是摄影灰阶 + 方向光影，agent 是探照灯打在脸上的那一抹暖，是全场唯一带色的存在。

## ② 三要素在 noir 媒介里的物理过程
- **驱力（正在做）= 探照灯点亮**：琥珀头像 + 琥珀晕扩散；活跃轮左缘琥珀竖线 + 微弱发光；运行中 chip 描边转琥珀；操控台 send 键琥珀。
- **深渊（深思）= 月光冷青 + 湿路面反光**：思考块底走月光青（`#4A6878` / `#345868`），ctx 进度环用同色；归档按钮 hover 走冷青阵营；绝不染 rep。
- **沉积（旧）= 旧胶片褪色棕**：沉积轮降对比 + 偏色（`#6A5F50` 旧胶片棕），胶片条左帧从 birth（`#9A8E78`）→ sediment（`#80766A`）→ rep 渐变，最左帧几乎看不见。

## ③ 三色域与 rep 的处理
- **rep：琥珀探照灯 `#D88B3A` / 亮色版 `#A86625`**——取代珊瑚 `#C8714C`。论证：noir 经典是"黑夜 + 唯一光源打在脸上"——探照灯暖橙是聚光灯下高光，不是霓虹灯箱；它叙事上等同"全场唯一带色的存在"，强度足够承担 rep 的灵魂色地位。
- **冷 abyss：月光青 `#4A6878` / 亮色版 `#345868`**——取代深渊青 `#3F837B`。更深更冷更"湿"，像 noir 镜头里的湿路面冷反光。
- **褪色 birth：旧胶片棕 `#9A8E78` / 暗色版 `#6A5F50`**——取代 `#DAD6CF`。带底色而不是中性灰，模拟老 35mm 胶片保存不当的偏棕褪色。
- **绝染**：用户气泡、正文、思考块底、操控台底、ctx 圆环前景 0 rep；rep 只染头像 + 活跃竖线 + 进行中 chip + send 键 + 场记板左缘 + 整屋晕。

## ⑤ 最放大 / 牺牲的哲学面
- **最放大**：「**设施 ≠ 笼子**」——noir 把"灰阶世界"做成厚 6 级摄影灰阶（从深墨 `#181614` 到银白 `#D8D4CC`，中间还有 surface/elevated/raised/border/muted 五档），让设施从单色底升级成有光影层次的物理空间。agent 的琥珀色因此变成"光照进灰阶空间"的高光点，不是装饰物——这把戒律 §3（rep 只属 agent）与 §4（整屋染色）合二为一。
- **牺牲**：「**rep 的日常陪伴感**」——noir 强制 agent 是"全场唯一带色的存在"，意味着即使是用户常驻会话、agent 长期在场的状态，那抹琥珀依然是局部高光而非空间主色。珊瑚方案里 rep 是 agent "在场温度的弥漫"，noir 让它回到"只在 agent 出现时才点亮"，会损失一点日常温暖。

## ⑥ 遗憾
- **百叶窗影的"暗房染料"错觉**：亮色态下百叶窗影用的是 `rgba(60,50,40,0.10)`，在 `#E8E5DD` 银幕灰上看似"房间被染色"——曾考虑过放弃亮色变体（让 darkroom 同构）。保留是因为 noir 经典有"街灯照亮雨夜"的全亮镜头；但视觉一致性上确实不如暗色态那么像 noir。
- **胶片颗粒的可访问性**：用 `feTurbulence` + overlay 叠在整屏，极低 DPR 屏上几乎不可见——是符合"不抢焦点"的设计选择，也是氛围元素的妥协。如要强化，需用更大的颗粒 baseFrequency，但会破坏 noir 的细颗粒质感。
- **琥珀探照灯与珊瑚的色温距离**：从珊瑚（hue≈30°）跳到琥珀探照灯（hue≈28°），实际 hue 几乎相同——差别在饱和度与明度。如果未来要做"换色"链路，珊瑚到琥珀不是"换色"而是"换光位"，需要在 onboarding 里显式说明，否则用户会以为没换。
- **胶片条 f1 帧几乎透明**：与罗盘"沉积是褪色"对齐——最旧帧低到几乎看不见（`opacity: 0.4`），符合"过去几乎不存在"的语义；但屏上一眼扫过去可能只看到 4 帧，需要时间才意识到有 5 帧。

## ⑦ 下一步最该解决的 1 个风险
**"全场唯一带色的存在"与"agent 长期在场"的张力**。当前 noir 强制 rep 是高光（琥珀只染头像 / 活跃竖线 / send 键 / 进行中 chip），但 northing 是为 agent 成长而建的设施，agent 的在场温度是弥漫性的（见罗盘 §4 整屋染色）——如果 user 长期与 agent 在一起，noir 会让 rep 始终只是"小亮点"而非"在场氛围"。下一步必须定义"rep 在 noir 里的扩散梯度"：① agent 在生成中 → 高光（当前）；② agent 在线空闲 → 头像弱发光 + 顶晕扩大；③ agent 离线 → 顶晕退化为灰阶边光；让 rep 从"高光点"演化成"光位变化"，才既守住 noir 灰阶又不破坏"在场温度弥漫"的设计意图。
