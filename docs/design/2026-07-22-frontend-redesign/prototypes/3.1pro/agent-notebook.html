Collaborators: UmR, Northing Agent (Active) · Last updated 2 mins ago
系统在启动的时候崩溃了，产生了一个 panic。
请检查初始化阶段的生命周期逻辑。
Northing Resolution
发现初始化顺序存在因果倒置：系统在尚未加载 config::init() 的情况下，提前调用了 memory::read_session()。
我已将配置加载的时序提前，并修复了相关依赖。
// src/main.rs
+ let config = config::init()?;
+ let session = memory::read_session(&config);
