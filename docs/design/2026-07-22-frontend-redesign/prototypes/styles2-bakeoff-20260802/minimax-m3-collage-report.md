# minimax-m3 · collage（贴纸桌）

## ① 风格命名与一句话主张
- **风格名**：`collage`（贴纸桌）
- **一句话主张**：northing 不是柔光咨询室，是一张旧牛皮纸桌——agent 的每一步都在纸上落物证：印章、邮票、胶带、便签。

## ② 哲学 according to collage 词汇
- **驱力（正在做）= 刚盖的朱砂印章**：鲜红、微渗墨水、边缘不锐——"它此刻在做事"的物证。
- **深渊（深思）= 胶带下的靛青墨水便签**：被半透黄胶带覆在左缘，靛青字迹写在大便签上——"它在深处"的视觉是被遮住但可读。
- **沉积（旧）= 卷边泛黄的旧贴纸**：右上角翘起、褪色、不再贴紧桌面——"它做过但已经过去了"的语义。

## ③ 三色域与 rep 的处理
- **rep**：从珊瑚 `#C8714C` 换为 **朱砂印章红 `#B83A30`**——更红、更稠、更"盖过章"。论证：珊瑚是"涌现的暖"；朱砂是"做过事的暖"，与"印章落款 = agent 痕迹"同源。
- **冷 abyss**：从深渊青 `#3F837B` 换为 **靛青墨水 `#3D5A6C`**——更蓝、更墨，像钢笔写的。
- **褪色 birth**：泛黄旧纸 `#A89875`——沉积轮的旧贴纸直接继承这个色。
- **绝染**：用户气泡/思考块底/正文/操控台底/沉积轮边框 0 rep；rep 只染印章、活跃批注线、刚盖的圆章 chip、编年史右端。

## ⑤ 风格最放大 / 牺牲
- **最放大**：**「agent 在场 = 物证」**。拼贴语言把"它在做事"从抽象晕染变成具体物品——印章、邮票、胶带、便签。这把戒律 §3（rep 只属 agent）和 §4（整屋染色）合并成"agent 是这张桌上唯一留物证的人"——视觉冲击力比现方案强一个数量级。
- **牺牲**：**「安静感」**。拼贴天生有信息密度（撕边、胶带、邮票穿孔、印章渗墨同时存在），即使每一件都被"小心放置"，视觉里物件比现方案多——对"心理咨询室基底克制"的纯度是有代价的，需要读者接受"纸桌本身就是高密度场景"这个前提。

## ⑥ 遗憾
- **离线字体的落差**：`'Patrick Hand'` / `'Caveat'` 等西文手写体非系统字体，CSS fallback 走 `'STKaiti' / 'KaiTi' / '楷体'`——中文环境的"手写落款感"是真实的，但西文 fallback 会让混合排版（如 chip 中的 `read`、`src/main.rs`）落到楷体，可读性下降。
- **撕边的实现妥协**：用户气泡的撕边用 `clip-path` 多边形硬写，没用 SVG `feTurbulence` + `feDisplacementMap`——因为后者在 user-bubble 上渲染成本偏高且跨浏览器一致性问题。所以撕边是"几何撕"而非"自然撕"，缺少纸纤维感的随机性。
- **暗色下胶带的可读性**：胶带用半透 rgba，在亮色 `#EDE3CD` 上很显眼，在暗色 `#1F1A12` 上对比度被压低——目前提亮胶带边缘色，但胶带本身的"半透感"在暗色下被削弱。
- **拼贴物品过多**：当前屏上有印章头像、邮票 chip、圆章 chip、撕边便签、胶带 banner、胶带操控台、撕边沉积轮、撕边用户气泡、撕边便签角——9 件物。如果再叠加（如未来在抽屉里也用同款语言），会有"物证展览"风险，需要节制。

## ⑦ 下一步最该解决的 1 个风险
**拼贴语言的"物证节制"协议**——目前每件物品都有意义，但屏上同时存在的拼贴元素已达 9 件；继续深化时（加入抽屉内子项、技能候选、已归档等的拼贴化）会快速滑向"风格展览"。下一步必须先定义一套"哪些位置留拼贴、哪些位置留空白"的密度协议——例如：抽屉内已归档区禁用撕边（保持留白）、主体对话区禁用贴纸（只在边缘允许胶带），把拼贴的"小心放置"从原则变成可执行的密度预算表。
