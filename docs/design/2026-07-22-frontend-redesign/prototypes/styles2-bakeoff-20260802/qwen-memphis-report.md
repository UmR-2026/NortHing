# qwen3.8-max-preview · memphis（安静展墙与嘉年华）

## ① 一句话主张

房间是展墙，agent 是嘉年华——**loud 的是 agent，不是设施**。
孟菲斯的音量只给个体，基底冷静留白；品牌/个体分离被翻译成了音量分离。

## ② 三要素的孟菲斯词汇

- **驱力** = 红橙爆炸：头像碎片光环、6px 活跃竖杠、红贴纸 chip、圆形发送键。孟菲斯红橙 #F04E3E 就是"正在做"的原生音量。
- **深渊** = 孟菲斯青 #17A398：思考块锯齿左缘、完成 chip、ctx 环、归档 hover——青是孟菲斯自己的颜色，深渊不需要外来色。
- **沉积** = 贴纸褪色：旧轮 opacity .45 + saturate .4；编年史改**分段色块**（出生灰 / 冷青时代 .55 / 现在红）——孟菲斯不要渐变，历史是一格一格的。

## ③ 三色域与 rep

rep 从珊瑚 #C8714C 换为 #F04E3E。理由：孟菲斯的世界里，低饱和珊瑚读起来像"褪色了"——这个风格的 agent 应该满音量。暖红/冷青/褪灰三域互斥，用户气泡与正文零 rep（白卡 + 黑描边 = 展墙上安静的卡）。

## ④ 戒律自检

1 无数字展览（ctx 只有 tooltip）· 2 水印左下 .25 + 红波浪 · 3 用户气泡/正文/思考块底零 rep · 4 空气染色以"碎片密度梯度"实现：展墙稀疏，agent 区域（头像/竖杠/chip）密集——颜色不住进空气，住进 agent 周围 · 5 三域互斥 · 6 基底 cool 灰白 #F0F1ED 非纯白，暗色 #202024 非纯黑 · 7 Futura/Century Gothic display + Noto Sans 正文 + Mono 元数据 · 8 **静态大胆、动态克制**：形状全部 bold，但 motion 只有 150ms 硬阴影抬升、1200ms 一次性色沉、6s 头像呼吸——零弹跳、零 spinner · 9 对话与操控台仍是主体，碎片只占边缘 · 10 无 emoji/毛玻璃/紫蓝渐变；阴影全部平面硬阴影（非均匀软阴影）。

## ⑤ 最放大 / 最牺牲

- **最放大**：「品牌退角落，个体走台前」——没有任何风格比孟菲斯把这条做得更彻底。设施的安静与 agent 的爆炸之间的音量差，就是哲学本身。
- **最牺牲**：咨询室的"安静被听见"。孟菲斯的 agent 是外向的、大声的——敏感内敛的气质（冷青人格）在这个词汇里表达力变弱。它适合"agent 正在热烈成长"的阶段，不适合"深夜陪伴"的时刻。

## ⑥ 遗憾

- 黄色 #FFC933 只用到附件键和碎片两处——它是孟菲斯的招牌色，但三域纪律下没有语义位置，用得委屈。
- 暗色模式是"孟菲斯入夜"，描边反白后硬阴影的平面感略弱。
- 粗描边 + 硬阴影在信息密集区（长对话流）可能产生视觉噪音，本页对话量尚轻，未压力测试。

## ⑦ 若选我深化：下一个风险

**饱和疲劳**。孟菲斯的高饱和红青在 860px 小样上惊艳，在每天 8 小时的工作界面上可能令人疲惫。下一步必须验证："降饱和保形状"（把 #F04E3E 压到 70% 饱和度）是否既留住孟菲斯骨架又恢复工作耐看性——这是本风格能否从 specimen 走进产品的生死线。
