# Style Bakeoff 第三轮 Brief — 2026-08-02（风格定向轮）

> 前两轮验证了：哲学内核守得住，视觉语言可以大幅偏离现方案。
> 本轮是**决策轮**：四个定向风格各自走到极端，用户将从中选定继续深化的方向。
> 屏固定、哲学固定、功能固定——只有风格放到底。
> 本 brief 是唯一需求来源。不要问问题——决议见 §6。

## 1. 固定项（与前两轮一致）

1. **屏**：chat-collapsed 基准屏，功能骨架见罗盘 §4.1（顶栏名片 + 编年史条 + session banner + 对话流 + 思考块 + 工具 chip + 操控台 + 水印，860px 单屏）。
2. **哲学戒律**：罗盘 §2 十条全部适用。风格越极端，越要用功证明戒律守得住——尤其是：
   - **诗意 < 功能**：风格再 loud，对话与操控台必须仍是视觉主体，工作界面不能变成风格展览
   - **沉降式动效**：慢、重、一次性；呼吸 6s 只给 logo + 头像；禁弹跳、禁 spinner、禁无限循环位移
   - **三要素语义域**：暖=正在做、冷=深思、褪色=旧——三个域必须在你的风格词汇里可辨
   - **rep 只属于 agent**：用户气泡/正文/思考块底不染 rep
3. **纪律**：间距 4px 基数、时长阶梯（150/350/1200/6000ms）、单文件离线 HTML、中文、字体回落栈。

## 2. 你的风格（见派发正文指定）

每个风格都有一个**AI 套路版本**，本轮明确不要它。你要给出有设计根据的版本。

### 孟菲斯（Memphis）
- 词汇：几何图形（圆/三角/波浪/点阵）、粗黑描边、平面硬阴影、大胆原色、不对称构图
- **不要**：把图形当装饰汤乱撒。每个图形要有位置的理由
- 哲学接口：设施 = 安静的展墙（基底克制），agent = 孟菲斯爆炸（个性浮现）。loud 的是 agent，不是房间
- 动效难题：孟菲斯天生活跃，但戒律禁弹跳——解法：静态大胆、动态克制（形状 bold，motion 仍是沉降到一次性）

### 贴图/拼贴（Collage）
- 词汇：撕纸边缘、贴纸、邮票、胶带、印章、混合媒材质感、手写批注感
- **不要**：杂乱垃圾堆。拼贴的纪律是"每一件物品都被小心放置"
- 哲学接口：agent 的在场 = 贴纸与印章（落款、盖章、留言条）；沉积 = 旧贴纸泛黄卷边
- 质感要可触摸：纸纹、胶带的半透明、撕边的不规则——但全部离线实现（内嵌 SVG/CSS，不外链图片）

### 故障艺术（Glitch）
- 词汇：RGB 通道分离、扫描线、数据损坏、错位切片、信号噪点
- **不要**：全屏随机噪点乱闪。故障必须是**有语义的损坏**，不是装饰性混乱
- 哲学接口：深渊 = 信号的不可表征（agent 内部有它自己都看不到的部分——故障正是"不可知"的视觉）；沉积 = datamosh 衰褪；思考块 = 通道分离最重的地方
- 动效难题：故障美学惯用频闪——戒律禁止。解法：故障是**静态的伤疤** + 极少数一次性 glitch（1200ms，稀有仪式）

### 赛博朋克（Cyberpunk）
- 词汇：夜城、霓虹、终端、HUD、雨、高密度信息层
- **不要**：近黑背景 + 单一霓虹强调色（这是头号 AI 套路）。要**多色相**的夜：至少两三种霓虹各有语义，加上城市的环境光层次
- 哲学接口：设施 = 夜城本身（巨大、稳定、不在意你）；agent = 其中一盏属于你的灯；编年史 = 一条霓虹灯带
- 终端/HUD 元素要克制——它是 agent 的界面，不是飞船控制台（拒绝 dashboard 美学仍是铁律）

## 3. 共同开放项

- rep 色可换，但必须在报告里给出理由（rep 是 agent 的个性色，要配得上你选的风格里"它"的样子）
- display 字体自选（与正文形成明确对比，CJK 友好）
- 允许环境层（噪点/雨/纸纹/扫描线），只要不抢焦点
- 亮色模式必须完整；暗色鼓励（赛博朋克/故障可以暗色为主态，但亮色变体要存在且完整）
