## 3. 逐条十诫自检
1. **拒绝 dashboard 美学**：【过】无 turns 计数、无 API 健康度，上下文采用无数字 SVG 进度环。
2. **品牌水印化**：【过】northing 同心环仅在左下角 0.25 透明度水印，主体为 agent 知序名片与头像。
3. **代表色是 agent 的灵魂**：【过】默认暖珊瑚 `#C8714C`；用户气泡、正文、思考块底完全不染 rep 色。
4. **整屋空气染色**：【过】基底使用预计算 `air-rep` 与头像锚定 `halo-rep-strong` 径向渐变，形成空间弥漫感。
5. **三要素语义互斥**：【过】暖 rep（活跃竖线/发送/呼吸）、冷 abyss（思考块左缘 `#3F837B`/完成 ToolChip）、灰 sediment（沉降历史轮 0.55 透明度）。
6. **沉降式动效**：【过】6s 呼吸仅给 logo 与头像；见证成长采用 1200ms 一次性过渡；无弹跳/无 spinner/无位移沉积。
7. **用户与 agent 边界**：【过】用户气泡右对齐 Surface 底色，无 rep 染色。
8. **诗意克制**：【过】无 emoji、无毛玻璃、无紫蓝渐变、禁用 box-shadow（全改用 drop-shadow）。
9. **暖灰基底**：【过】亮色 `#F4F3F0` / 暗色 `#181612`，支持完全离线双模式切换。
10. **字体三系**：【过】Fraunces / Noto Sans SC (400) / JetBrains Mono 严格回落栈，无外链网络依赖。
