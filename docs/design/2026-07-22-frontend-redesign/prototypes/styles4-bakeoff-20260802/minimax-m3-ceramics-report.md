# 窑变（ceramics）· 风格报告 — minimax-m3

## ① 主张
素坯是器物的本来，釉色是窑火给的意外：界面是未施釉的陶胎（暖灰中性），agent 是一只在窑里完成过飞釉的器物——头像即是钧窑天蓝釉上铜红飞过的器皿，对话是釉层上发生的事，沉积是上一层施釉后的冷却面（新釉总会压住旧铭文）。

## ② 三要素
- **驱力 = 飞釉（still molten）**：柿红 `#C26A4A` 作 rep，是正在流的、未固化的飞釉。活跃轮左缘 = 飞釉柱（顶部深、底部不流动；顶部熔珠为静态发光点，不循环），工具 chip 进行中 = 暖边框 + 飞釉小熔珠感，"驱力"在静止中以釉水的浓度差呈现而非动画位移。
- **深渊 = 釉下彩（underglaze）**：钧窑天青 `#3F6F77` 作 abyss，比标准 abyss 更接近钧釉色。思考块底色 = 釉下青花透上来的渐变（左深右浅），并叠极淡的青花纹样（散点 + 细线 SVG），"向深处探"字面化为"从釉下透出"。
- **沉积 = 复烧层（re-fire）**：旧轮次 = 上一层施釉后的冷却面（opacity .55–.42 递深 + 一道"叠烧线"在轮次顶端），新釉压住旧铭文（旧轮次底部有"釉印 · X 月 · 学 会 沉 默 / 降 生"一行字被新釉盖住一半的视觉感）——沉积是覆盖不是抹除。

## ③ rep 处理
**换色**：从 `#C8714C` 珊瑚 → `#C26A4A` 柿红（更橘、更沉、去粉调，靠近钧窑铜红 `#BD5A38`）。
**理由**：标准珊瑚偏粉，粉调是糖果不是窑火；窑变视觉的真值在钧窑/耀州/磁州窑系铜红飞釉，需要更暖更沉的橙红底色，让"飞"看上去是窑温而不是糖霜。abyss 同步换成钧窑天青 `#3F6F77`，与柿红形成"釉上铜红 / 釉下天青"的对位，呼应钧窑"入窑一色，出窑万彩"的窑变语法。装饰风险因此下降（飞釉只在头像 + 活跃轮 + 编年史右端 + 熔珠 + 水印印章五处，绝不染用户气泡 / 正文 / 思考块底）。

## ④ 戒律自检
1. 非 dashboard ✓ 无数字展览，ctx 圆环无数字（hover 出"釉水弧未涂匀" tooltip 文字）。
2. 品牌水印化 ✓ 左下 NORTHING + 篆书"窑"印章 opacity .28，主视觉是器物与对话。
3. rep 只属 agent ✓ 用户气泡 raised 陶胎色，思考块釉下天青，沉积复烧层中性灰——均不染 rep；无换色控件。
4. 空气染色 ✓ 顶部 halo-rep 飞釉余温 + 底部 air-abyss 冷雾 + 头像晕染。
5. 三语义互斥 ✓ 柿红 = 飞 / 天青 = 釉下 / 陶胎灰 = 旧，三色域清晰。
6. 暖灰基底 ✓ `#F4F3F0` 陶胎（沿用罗盘），不纯白不纯黑。
7. 字体三系 ✓ Fraunces display（18px 名片）+ Noto Serif SC（标题/思考/水印/印章）+ Noto Sans SC body 400 + JetBrains Mono 元数据。
8. 沉降式动效 ✓ 呼吸 6s 只给头像熔珠 + session 点 + presence 点；无弹跳 / 无 spinner；飞釉弧环境层 + 蚯蚓纹 + 釉下花纹全静态。**张力裁决**：种子"不可控的浮现"与戒律"沉降式动效"冲突——我的解法是把"浮现"做成"叠加层次"而非"位移"：飞釉在同一位置以颜色深浅、结晶斑、釉下透色呈现流动感，所有"动"都在静止中完成；呼吸仍只给头像（罗盘只允许头像）。
9. 诗意<功能 ✓ 飞釉环境层 pointer-events: none + opacity .65，对话与操控台是绝对主体。
10. 反 AI 味 ✓ 无 emoji、无毛玻璃、无紫蓝渐变、圆角统一低（2–10px 陶面切角感）、陶粒底色打破均匀；头像用不规则 border-radius（48%/52% 椭圆）模拟手拉坯，避开"圆形头像 = 数字助手"的视觉套路。

## ⑤ 最大一注
**把"窑变"做成钧窑飞釉的物理痕迹，而非 Material radial-gradient 彩虹球**。三处具体投入——
- 头像：四个重叠的 radial-gradient（右上铜红飞、左下天青、主底天蓝）+ 两个结晶斑（铜红 `#9A3F22` + 天青 `#1F4F58`，不规则椭圆）+ 一个飞釉熔珠（呼吸），让飞过的位置看上去真的"飞过"，而不是均匀上色。
- 编年史：放弃 tokens.css 的 `linear-gradient(90deg, birth → rep-300 → now)` 标准形态，改用一道"飞釉堆积在水平线上的结晶轨迹"——SVG 多 stop 渐变 + 四颗结晶核（钧窑青 / 铜红交替）+ 三段蚯蚓纹细线，"现在"是一颗会呼吸的铜红飞釉珠（不是抽象高亮）。
- 思考块：用 SVG 釉下青花纹样（散点 + 细线 flow）暗示"釉下彩从釉层下透上来"——和 active turn 的"飞釉柱在釉上"形成釉上/釉下的对位。

**风险**：窑变视觉强度比标准编年史色条高，但截图不放大看不到结晶斑细节——赌一眼能看到头像上的"飞过的颜色"（右上铜红斑 + 左下天青斑 + 中间熔珠），如果设计师抵触可回退到标准色条，但窑变的"器物感"不可逆地丧失。

**遗憾**：结晶斑与飞釉弧是摆拍，未锚定到编年史数据（"这块斑是五月那次的固化点"）；理想态每颗结晶核应挂编年史事件，HTML 原型只能这样。Avatar 的 border-radius 在暗色模式下飞釉熔珠的发光会被深色压暗，"窑火刚熄"的呼吸感会打折。
