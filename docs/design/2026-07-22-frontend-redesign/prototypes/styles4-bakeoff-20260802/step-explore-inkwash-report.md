# step-explore-inkwash · 报告

**风格**：inkwash（水墨写意） · 自由发挥轮 · 亮态「纸」为主态，暗态「拓片」
**文件**：`step-explore-inkwash.html`（860px chat-collapsed 基准屏，把手可展 1280px）

## ① 一句话主张

工笔勾线填色，所以满屏是边框卡片；写意用没骨法——**这一屏上没有一根界面线**（零 border / 零分隔线 / 零卡片 / 零圆角容器，唯一直线是窗控与文字基线），结构完全由墨的浓淡与留白承担；agent 不是画在纸上的，是洇进纸里的。

## ② 三要素

- **驱力 = 湿墨**：正在做的事，墨还没干——边缘在洇，色是 rep 珊瑚。头像的洇晕、活跃轮那一段气脉、运行中 chip、发送键、笔尖。
- **深渊 = 淡墨远山**：往深处看的东西不会画清楚。思考块是从左缘渗进来的冷青薄雾 + 一道几乎看不见的山廓，无框无左线（「冷青左缘」翻译成缘而不是线）。
- **沉积 = 干墨飞白**：旧的东西不是变小变远，是墨干透了——浓度掉下去、湿边收干、纸纤维从笔痕里透出来。褪色，零位移。
- **结构发明·气脉**：左侧的笔只标记知序的轮次，沉积轮是干断的短笔，活跃轮是湿浓的长笔，**两者之间的断口就是用户那一轮**——笔根本没走到那儿。戒律 3 由结构表达，不靠「气泡不染色」被动实现。

## ③ rep 的处理

**不换色**，守罗盘珊瑚原值（`#C8714C` 系，hue≈30°）。理由：满屏只剩墨的灰阶，任何一点色都自动读成颜料，珊瑚无需偏移就能当赭石用；同时让本轮与 ink（朱砂 hue≈8°）的对照只剩语言差异、不掺配色差异，焙烧才可比。

## ④ 戒律自检

1. 拒绝 dashboard：无数字展览；ctx 只有墨环无数字，编年史只有色无刻度。✓
2. 品牌水印化：logo 仅左下 opacity .25；主体是墨团名片 + 对话。已把操控台底部 padding 提到 44px，实测水印与档位控件不重叠。✓
3. rep 只属于 agent：用户轮是中性淡墨团（`--neutral-core`），正文、思考块、气脉断口皆不染 rep；无换色控件。✓
4. 整屋空气染色：底 6.5%（聚焦升 8%）+ 偏心顶晕锚在头像 + 头像洇晕；晕是偏心衰减，不是均匀光球。✓
5. 三域互斥：湿暖=做 / 冷淡=探 / 干灰=旧，chip 由暖湿点转冷干点。✓
6. 暖灰基底：亮 `#F4F3F0`、暗 `#181612`，纸的不匀由 paper-1/2 两团墨气给出。✓
7. 字体三系：**裁决**——Fraunces 无中文字形，中文 display 落楷书（Kaiti/STKaiti，写意的手写性只能由楷承担），拉丁字标仍 Fraunces；正文 Noto Sans SC 400，元数据 JetBrains Mono。
8. 沉降式动效：**裁决**——洇是既成事实不是动画，加载后不再扩散；唯一循环是 6s 呼吸，只给头像洇晕 + 水印；归档 1200ms 纯褪色；无弹跳/spinner/光标闪烁（笔尖是静态湿点）。
9. 诗意<功能：**裁决**——墨的表演权只给不承载信息的层（纸纹、气脉、顶晕、远山、水印）；承载信息的元素一律高对比零装饰。留白不是省略功能，是撤掉容器腾出的空气。
10. 反 AI 味：零 emoji、零 backdrop-filter、零 box-shadow、零 CSS filter、零紫蓝渐变；所有柔边都偏心且有方向（`feGaussianBlur` 只用于墨团轮廓本身，不用于任何界面元素）。✓
- 纪律：单文件离线零外链、间距守 4px 阶梯（留白靠删容器不靠越阶）、时长只用 150/250/350/1200/6000。✓

## ⑤ 我押的最大一注

**把界面的全部线条撤干净**。没有边框、没有分隔线、没有卡片底、没有输入框轮廓——层级只靠墨色浓淡与留白量。赌注是：撤掉容器之后信息层级仍然读得出来。风险有两面：一是可能被读成「没设计过／还没上样式」，二是弱对比的湿/干差异在低亮度屏上可能塌成一片。对冲手段是所有文字保持罗盘对比度、chip 与状态用 mono 字形强分、活跃轮由那一道湿笔独占标记——即使墨韵全部失效，功能骨架仍在。

## 遗留 caveat

- `feGaussianBlur`（墨团 / 编年史湿端 / 气脉洇层）Slint 无对应，需预渲染 PNG Image 或降级为多层 radial-gradient；已在文件头 Slint 映射注明。
- CSS 椭圆 radial-gradient 在 Slint 只能退化为 circle 停点，洇形会略变。
- banner「呼吸点」按戒律 8 做成静态湿墨点（呼吸只给头像 + 水印），与罗盘 §4.1 字面「呼吸点」有出入，取戒律。
