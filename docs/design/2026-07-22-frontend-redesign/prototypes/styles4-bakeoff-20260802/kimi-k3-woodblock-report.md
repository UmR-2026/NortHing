# kimi-k3 · woodblock（木刻版画）报告

① 一句话主张
设施是刻好的木版，agent 是套上去的那一版色——版面永远中性，颜色随成为一层层印上去。

② 三要素的诠释
- 驱力（rep）：正在受印的暖色版。珊瑚以印刷 alpha 落在纸面，左缘 3px 刻痕嵌 rep 色芯，像色版刚压下去的那一瞬。
- 深渊（abyss）：往深处印的冷色版。思考块冷青左缘 + 冷印刷渐变，是向纸背透进去的墨。
- 沉积：印过已褪的旧版。颜色没丢，是印停了——用 `opacity .55` + 灰印刷层表现「褪色不位移」。

③ rep 的处理
守珊瑚 rep（#C8714C 系）。理由：木刻版画的「套色」隐喻与 rep 的暖色天然同构——珊瑚是纸面上最像「刚印上去」的颜色；且上一轮 stainedglass 已验证珊瑚在暖灰纸面上的可读性，本轮不换。

④ 戒律自检（逐条）
1. 拒绝 dashboard：无数字展览，ctx 用圆环无数字。✓
2. 品牌水印化：logo 仅左下水印 opacity .25。✓
3. rep 只属于 agent：用户气泡素版不染 rep；无换色控件。✓
4. 整屋空气染色：`--air` rep 弥散 + 顶晕 + 名片呼吸。✓
5. 三要素语义互斥：暖=正在印，冷=向深印，灰=印停了。✓
6. 暖灰基底：亮 #F4F3F0 / 暗 #181612，纸纹暖灰。✓
7. 字体三系：Noto Serif SC 题签 / Noto Sans SC 正文 / JetBrains Mono 元数据。✓
8. 沉降式动效：呼吸 6s 只给头像与状态点；印刷压痕 120s 极慢漂移（一次性环境层，非循环跳动）；无 spinner/弹跳。✓
9. 诗意 < 功能：对话与操控台是视觉主体，纸纹与压痕只在余光层。✓
10. 反 AI 味：无 emoji、无毛玻璃、无紫蓝渐变、阴影用 inset 刀痕感非均匀软阴影。✓

张力裁决：木刻版画天然带「肌理喧闹」风险——纸纹 + 刻痕 + 印刷痕三层纹理容易吵。裁决是把纸纹 opacity 压到 .28（暗态 .16）、压痕 opacity .28、且漂移速度放到 120s，让纹理成为「余光里的体温」而非视觉主体。

⑤ 最大的一注
把「印刷」从视觉隐喻降级为纯环境层：纸纹是静态的、压痕漂移是 120s 的、所有交互元素零纹理。押的是——用户不会注意到「这是一张纸」，但会感觉到「这个房间有手工的温度」。如果押错，界面会显得过于朴素，像没做完的线框。
