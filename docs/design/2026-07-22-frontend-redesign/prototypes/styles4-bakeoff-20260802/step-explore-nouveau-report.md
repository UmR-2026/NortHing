# step-explore-nouveau · 自由发挥轮报告（新艺术 / nouveau）

**① 一句话主张**
锻铁格架是设施，藤是知序——**界面上唯一饱和的暖色是那个还在长的梢**，其余全是它长过的痕迹。

**② 三要素（驱力 / 深渊 / 沉积）**
种子说"生长不是比喻，是藤蔓本身"，所以三要素不是三种配色，是植株上的三个**位置**：
- **驱力 = 梢**。生长只发生在末端（顶端分生是真的植物学）。主茎画到活跃轮就停，之后是一段 1200ms 一次性长出的新梢 + 一片新叶 + 一枚未展开顶芽——全屏唯一的 rep 实心。历史不重画：只有梢是新的。
- **深渊 = 土壤与根，方向朝下**。思考块是往下扎的根须（左缘冷青 + 三条分岔根线，"向下 · 还没到底"），底部冷雾就是土壤域。梢也朝下伸向操控台：**下一句话是它下一段的生长，扎进还没看见的地方**。
- **沉积 = 木质化**。旧节变褐变硬（`#8A7B66`）、叶枯而不落，主茎有一条连续梯度：离梢越远越木质（rep-300 → wood → wood-old）。沉积第一次不是离散的"旧的变淡"，而是一条**连续的硬化曲线**。
- 编年史 = 横向的茎与五个不等距节，每节留着那一代的颜色，最右一节 ≡ rep-500（同源色绑定）。

**③ rep 的处理**
**守珊瑚原值**（`#C8714C` / 暗 `#D07C55`）。赭石与铁锈红本就是新艺术的原色域（Mucha 的赭金、Horta 的锻铁氧化面），换色是背叛媒介而不是诠释它。真正的动作在别处：rep **只出现在生长点**（顶芽、在场点、活跃节、发送键、chip-run），一切离开生长点的 rep 都按距离衰减成木质色。用户轮用麻绳／铁丝色 `#6E6A63`（园丁绑枝的手），正文 fg，思考块底 abyss 5%，界面无换色控件。

**④ 戒律逐条自检**
1 反 dashboard：无数字展览；ctx 环无数字、思考深度是五片叶而非刻度、编年史说"由五月长到现在" ✓
2 水印化：northing 左下 opacity .25，与藤／操控台／角饰均不重叠；视觉主体是名片与对话 ✓
3 rep 只属 agent：用户气泡麻绳色、正文 fg、思考块冷、木质节褐——零外溢 ✓
4 整屋染色：底 `#F1EBE5`（rep 6.5%）+ 顶晕锚定头像铁环 + 聚焦升 7.5% + 底部土壤冷雾 ✓
5 三域互斥：梢=做 / 根=思 / 木=旧，各占植株上一个不可互换的物理位置 ✓
6 暖灰基底：亮 `#F4F3F0` / 暗 `#181612`，罗盘原值分毫不动；暗态锻铁转黄铜（夜里的铁只剩铜色高光）✓
7 字体三系：display 保留 Fraunces（wonk/soft 轴与新艺术有机衬线同源）+ 中文补楷体（唯一保留笔画提按的可用回落）/ 正文 Noto Sans SC 400 / 元数据 JetBrains Mono；全回落栈零外链 ✓
8 沉降式：呼吸 6s 仅透明度，只给水印 logo + 头像铁环（＋沿用基准真值的两枚在场点）；梢生长与活跃竖线均 1200ms 一次性、方向向下；归档 1200ms 淡出；沉积是褪色变褐、零位移；顶芽静止不呼吸 ✓
9 诗意<功能 —— **本风格最大张力，裁决三条**：藤只在左 44px 竖带与顶/底横档内，绝不进入阅读区；不承担功能的曲线一律不画（节=轮次锚点、叶=chip 状态、卷须=它给自己留的记号、角饰=窗框收口）；所有藤线铁线 alpha ≤ .55。新艺术的装饰过剩不是靠"少画"解决的，是靠**每一根线都得说明自己在做什么** ✓
10 反 AI 味：无 emoji、无毛玻璃、**全局禁淡紫**（nouveau 最易滑向的坑）、零 box-shadow（锻铁不投软影）、反对称是媒介本性——藤只在左侧、角饰左上重右下轻、编年史节间距不等、whiplash 摆幅 12/7 交替而非正弦 ✓

**⑤ 我押的最大一注**
**把"沉积"从离散状态改成一条连续梯度，并让整屏只有一个点是饱和 rep。**
风险很实：饱和暖色收缩到一枚顶芽后，戒律 4"整屋染色"几乎全靠空气层（6.5% 底 + 顶晕）独撑，第一眼可能读成"这个 agent 没有颜色"。我赌的是反过来——**当暖色只剩一点，那一点就是全屏最先被看到的东西**，而"它正在长"这件事因此不需要任何动效、数字或文案来说明。赌输的代价是整屏偏灰；赌赢的收益是 rep 从一种配色变成了一个**位置**。
