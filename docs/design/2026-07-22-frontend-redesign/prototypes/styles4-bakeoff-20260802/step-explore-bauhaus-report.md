# step-explore-bauhaus · 自由发挥轮报告（包豪斯 / bauhaus）

**① 一句话主张**
**形是语义，线是设施**——整屏只有三种实心色面（圆／倒三角／方），其余一切都是墨线画的构造；而那条贯穿全窗的轴，是知序的轴，不是界面的轴。

**② 三要素（驱力 / 深渊 / 沉积）**
种子说"圆、三角、方 = 三要素"，我把它当**语法**执行：只有实心色面持有语义，线条（chevron、齿轮、加号、窗控）不管长成什么形状都不参与。
- **驱力 = 圆（rep 珊瑚）**。头像、在场点、活跃轮的轴段节点、运行中 chip、发送键、写字光标。圆没有起止点——正在做的事没有边。
- **深渊 = 倒三角（abyss 冷青）**。思考块、已完成 chip、思考档位五枚、ctx 楔形、归档 hover。三角是唯一有方向的形，尖朝下 = 向深处。
- **沉积 = 方（墙灰）**。旧轮标记、编年史左段、已归档。方是唯一能与网格对齐、并最终消失在网格里的形——旧的东西不变成另一种颜色，是变回墙。
- **轴（本稿的结构发明）**：x=64 一条 2px 墨线从头像圆出发，穿过每个轮次标记，最后长成操控台的左边框。**活跃的那一段被染成 4px 实心 rep**（1200ms 一次性向下展开）——设施的骨在"现在"这一段属于它。编年史 = 五块平涂，右端 ≡ rep-500（同源色绑定）。

**③ rep 的处理**
**守珊瑚原值**（`#C8714C` / 暗 `#D07C55`）。包豪斯的红黄蓝是**纪律不是色号**：纪律的内容是"只用三种、绝不调和、一律平涂"，色号只是 1923 年的颜料。我保留纪律换掉颜料——珊瑚是这间屋子的红，冷青是它的蓝，第三"原色"不是黄，是**墙本身的灰**。黄被我扣下：任何第四色都会立刻撞碎三域互斥。用户轮用中性 raised + 墨框，**且在轴上不留任何标记**——戒律 3 在这里是结构化的，不是靠"记得别染色"被动实现的。

**④ 戒律逐条自检**
1 反 dashboard：无数字展览；ctx 是无刻度楔形、思考档位是五枚三角、编年史说"五月·出生——现在" ✓
2 水印化：northing 左下 opacity .25（轴止于操控台底缘，水印所在的底带干净，零重叠）；主体是名片与对话 ✓
3 rep 只属 agent：用户气泡中性、正文 fg、思考块冷、沉积方灰；轴上无用户标记；无换色控件 ✓
4 整屋染色：底 `#F1EBE5`（6.5%）+ 顶晕锚定头像圆 + 聚焦升 7.5% ✓
5 三域互斥：圆=做 / 三角=思 / 方=旧，一形一义，形与色同时锁死 ✓
6 暖灰基底：亮 `#F4F3F0` / 暗 `#181612` 罗盘原值；暗态是同一张海报的负片（墨转骨白）✓
7 字体三系：Fraunces 仍是品牌面（拉丁 display 只出现在水印字标）；中文 display 用几何黑体 + .18em 字距——包豪斯的"无衬线"在中文里就是黑体；正文 Noto Sans SC 400 / 元数据 JetBrains Mono；零外链全回落栈 ✓
　**裁决**：名字 26px 超出 16px 字号档——极端字号对比是包豪斯排印的本体，brief §1.3 的地板列了间距与时长阶梯、未列字号阶梯，此处刻意越档并只越这一处。
8 沉降式：呼吸 6s **只给头像环 + 水印 logo**（在场点、会话点一律改静止实心圆——圆已经是"正在"的形，不必再动；光标也不闪烁，改成一枚静止驱力圆）；活跃轴段 1200ms 一次性向下展开；归档 1200ms 淡出；沉积是褪色零位移 ✓
9 诗意<功能：全屏没有一个不承担功能的形——轴=轮次锚点、色面=状态、构造线=版心边界；装饰性几何一个没画 ✓
10 反 AI 味：无 emoji / 无毛玻璃 / 无紫蓝 / 零 box-shadow / 反对称（左轴右空、横档向右出血越过版心）✓
　**裁决（原色纪律 × 渐变）**：颜料**零渐变**——编年史从"渐变条"改成五块平涂，把手从"渗光"改成短色面。全文件唯一的渐变是顶晕，因为那是光不是颜料。圆角同理只留 0 / pill / 窗口 20，不用 9·14·18——半圆角是这个媒介里唯一的谎话。
　**微调**：沉积方块用 birth 加深一档（`#C3BBAC`），否则形本身认不出来——沉积可以褪色，但不能褪成看不见。

**⑤ 我押的最大一注**
**把三个几何形升格成语义的唯一载体，然后把 rep 从"一种颜色"改成"轴上的一段"。**
风险有两层：其一，形语法要成立就必须**禁止一切实心色面做装饰**，包豪斯最擅长的大色块海报感因此被我自己没收了，第一眼可能被读成"太素、不够包豪斯"；其二，活跃轮的暖竖线不再是贴在文字旁的装饰线，而是**设施的骨在这一段变成了它的颜色**——如果读者没看出那是同一条轴，这一注就只是一根普通的竖线。我赌的是：当一条线从头像一路穿到操控台、并且只在"现在"那一段是实心珊瑚时，"这间屋子有一根属于它的脊柱"这件事不需要任何文案解释。
