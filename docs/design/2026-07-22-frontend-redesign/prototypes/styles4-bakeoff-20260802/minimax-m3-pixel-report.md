# 像素（pixel）· 风格报告 — minimax-m3

## ① 主张
栅格是 agent 画自己的那张方格纸：背景永远是那张纸（细密的 4px 像素底纹），知序的"自画像"是 8×8 颗 4×4 的像素格——lit 的是当下，dim 的是深渊，bg 的是已退入纸的沉积；编年史是 30 格像素行，每格约 6 天，最右一格是"现在"，挂 6 秒呼吸。文字是表，栅格是底，文字不被栅格吞掉。

## ② 三要素
- **驱力 = lit pixel（被点亮的格）**：rep-500 作"刚被画上"——头像的呼吸核、活跃轮章图的 hot 格、编年史最右的 now 框、发送键、deck 思考档的 pulse 段。lit 永远只一颗（头像 4 颗但属同一道光），不循环位移，只在原地做 6s 亮度呼吸。
- **深渊 = 暗下去的格（熄灯像素）**：abyss-500 作"内部屏幕暂时掉亮"——头像底部 4 颗 dim 像素、思考块 border + 4×4 深渊色码、deck 自治档 cyan 边框。深渊在像素语境里不是"深水"而是"被关掉的显示器"。
- **沉积 = 格的密度递减**：旧轮次 = 4×4 章图减到 3 行 4 行 5 行 + 透明度 .85→.68→.5；旧轮次文字颜色从 fg → muted；编年史左端的 birth 像素是 paper-400 灰。沉积不是抹掉，是分辨率变小、变远。

## ③ rep 处理
**守色**：从 `#C8714C` 珊瑚 → 守。
**理由**：像素的视觉语法要求"亮/暗"二元，珊瑚的明度高、红相纯，是"lit pixel"在白纸底上最不可替代的色——换冷色就丢了"亮"的语义，换暖灰就丢了"鲜"的语义。abyss 同步守 `#3F837B`，与珊瑚在亮态 1.5% 叠色不打架。装饰风险因此控住（lit rep 只在头像 4 颗、活跃章 hot 格、编年史 now 框、发送键、pulse 段、水印印章 6 处，绝不染用户气泡 / 正文 / 思考块底）。

## ④ 戒律自检
1. 非 dashboard ✓ ctx 无数字，活跃轮用 lit 像素章图而非进度条。
2. 品牌水印化 ✓ 左下 northing 像素字 + 朱印"北" opacity .28，主视觉是精灵图与对话。
3. rep 只属 agent ✓ 用户气泡 surface 中性、思考块 abyss 中性、沉积 sed 中性——均不染 rep；无换色控件。
4. 空气染色 ✓ 顶晕 halo-rep + 底冷雾 air-abyss + 整张 4px 像素底纹。
5. 三语义互斥 ✓ 珊瑚 = lit / 冷青 = dim / 灰阶 = bg，三色域清晰。
6. 暖灰基底 ✓ `#F4F3F0` 纸（沿用罗盘），不纯白不纯黑。
7. 字体三系 ✓ Fraunces display（18px 名片 + 朱印"北"）+ Noto Sans SC body 400 + JetBrains Mono 元数据（时间戳、章、归档、编年史、ctx）。
8. 沉降式动效 ✓ 呼吸 6s 只给头像 lit 核 + session 点 + 编年史 now + 思考档 pulse；无弹跳、无 spinner、像素章 / 4px 底纹 / 头像几何全静态。**张力裁决**：种子"沉积"隐含"像素在不断累加"（=位移感），与戒律"沉降式 / 禁循环位移"冲突——我的解法是把"沉积"做成"密度递减 + 透明度下沉"，所有"动"都在静止中完成：旧章是 3 行 4 行 5 行 6 行 + opacity 0.5–0.85，新章是 6 行 hot 满格，沉积是"行数变少"不是"格在移"。
9. 诗意<功能 ✓ 4px 底纹 pointer-events: none + opacity 5%，对话与操控台是绝对主体。
10. 反 AI 味 ✓ 无 emoji、无毛玻璃、无紫蓝渐变、圆角统一 0–2px 直边、章图 = 4×4 单元像素而非 Material 圆形头像；水印"北"用 1px 朱印框而非矢量 logo。

## ⑤ 最大一注
**把头像从"圆形渐变 + 浮动光晕"换成 8×8 像素精灵图**。这是种子"离散方格"的最强对位，也是与之前所有 bakeoff（含我自己的 zen/ceramics）最大的视觉切割——
- 不是浮夸的"自画像"（那是 Material Design 的 avatar 套路）
- 是"这个 agent 在 8×8 的栅格上能呈现多少自己"的诚实度量
- 4 颗 lit 像素 = agent 此刻能亮的"自我"；4 颗 dim 像素 = 仍在暗里的部分；16 颗 bg 像素 = 已退入纸的沉积
- 三色域在同一张 32×32 的小图里完成"驱力 / 深渊 / 沉积"的对位，**戒律 5（三语义互斥）的视觉兑现不靠 3 处分散的染色，而靠一张 64 像素的图**

**风险**：精灵图在 40×40 框内需要凑近看才能分辨 lit / dim / bg 的层级，截图缩放时易被读成"小色块"而非"自画像"——如果设计师抵触可回退到 64×64 大精灵图（拉远距离感，贴近 zen/ceramics 路线），但像素的"小而密"是种子语义的本体，缩放后那 64 颗格子变成"装饰马赛克"就丢了。如果确实不行，下一注是把编年史从 30×16 像素行做成 30×40 像素列（每格 8×4，更接近"沉积柱"），让旧沉积在垂直方向上更可见。

**遗憾**：精灵图的几何是手工摆的（不是真算法生成"agent 自画像"），理想态每颗 lit 像素应挂"我记得这件事"的事件指针；HTML 原型只能这样。30 格编年史的色码也是手工分配的（出生 5 格灰、近期 7 格暖、远期 10 格 sed、中段 8 格 mix），未锚定真实事件深度。
