# kimi-k3 · stainedglass（彩窗）报告

① **一句话主张**：铅框永不改变，颜色是穿过它的光——设施是铅条与暖灰，agent 的一切色彩都以 alpha「透光」呈现，而非平涂。

② **三要素**
- 驱力 = 受光的暖玻璃：rep 以 `--rep-pane`（16% alpha）透进活跃轮左缘、运行中 chip、编年史右端 c4 格——颜色是光，不是漆。
- 深渊 = 冷玻璃：思考块/完成 chip/ctx 圆环用 abyss-pane，光从冷色那边透过来，「向深处探」即背光面。
- 沉积 = 褪光的旧玻璃：颜色还在玻璃里（五月那块冷青仍在编年史 c3），光不再从那儿进来——opacity .55 + old-pane，褪色不位移。

③ **rep 处理**：守珊瑚（C8714C 系）。理由：彩窗的语法是「光穿过玻璃」，rep 作为唯一受光暖色源，与 abyss 冷玻璃互为光路两极；换色会破坏「同一扇窗」的叙事。

④ **戒律自检**
1. 拒绝 dashboard ✓ 无数字展览，ctx 环无数字。
2. 品牌水印化 ✓ 左下 opacity .25，主体是名片+对话。
3. rep 只属于 agent ✓ 用户气泡=中性铅框玻璃（raised 暖灰，透自然光，不染 rep）；无换色控件。
4. 整屋空气染色 ✓ `--air` 5.5% 全窗 + 顶部晨光晕 + speaking 升档 7.5%。
5. 三要素互斥 ✓ 暖=做、冷=思、灰=旧，语义见②。
6. 暖灰基底 ✓ 亮 #F4F3F0 / 暗 #181612，沿用罗盘值。
7. 字体三系 ✓ Fraunces 栈（Noto Serif SC 兜底，离线无外链）/ Noto Sans SC 正文 400·500 / JetBrains Mono 元数据。
8. 沉降式动效 ✓ 呼吸 6s 仅 logo 头像+两处呼吸点；无弹跳/spinner。**张力裁决**：彩窗天然引人做「闪烁的光」，改为 120s 极慢单向漂移的光带投影（不循环跳动、可 reduced-motion 关停）——让光动得像太阳，不像霓虹。
9. 诗意<功能 ✓ 光带 opacity .35 压在内容层下，对话/操控台始终是视觉主体。
10. 反 AI 味 ✓ 无 emoji/毛玻璃/紫蓝渐变/均匀软阴影；头像高光用 inset 定向光。

⑤ **最大的一注**：把「颜色」全部改写为透明度（pane = alpha 光），而不是实体色面——所有 rep/abyss 出现处都是「铅框 + 透光」。押的是：截图里色彩会显得克制到近乎素，但「光是穿过去的」这一质感差异能被一眼认出；若败，整屏会偏灰、被读成「未完成上色」。
