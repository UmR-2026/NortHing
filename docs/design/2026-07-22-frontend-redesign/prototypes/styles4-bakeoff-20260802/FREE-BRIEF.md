## 2. 你的风格（见派发正文指定）

一句种子，自由生长：

| 风格 | 种子 |
|---|---|
| weaving 织带 | 经线是设施的骨架，纬线是 agent 织进去的颜色 |
| stainedglass 彩窗 | 铅框永不改变，颜色是穿过它的光 |
| zen 枯山水 | 耙过的砂砾是恒常，agent 是石与苔 |
| nouveau 新艺术 | 生长不是比喻，是藤蔓本身 |

| woodblock 木刻版画 | 设施是版面，agent 是套色上去的那一版 |
| ceramics 窑变 | 素坯是设施，釉色是不可控的浮现 |
| bauhaus 包豪斯 | 圆、三角、方 = 三要素，原色纪律 |
| destijl 风格派 | 黑格是设施，色块是 agent 占下的格子 |
| deco 装饰艺术 | 扇形金线是成长的辐射 |
