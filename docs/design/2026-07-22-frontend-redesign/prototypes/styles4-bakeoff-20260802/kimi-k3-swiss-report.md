# kimi-k3 · swiss（瑞士国际）报告

① **一句话主张**：整个界面是一张制版稿——暖灰纸面、发丝线、12 栏底纹与四角对位十字是永远中性的网格，agent 的一切只被允许出现在「一个红色信号位」上；极端的字体对比（34px grotesk 名字 vs 10px mono 元数据）取代一切装饰。

② **三要素**
- 驱力 = 被占下的信号位：同一个信号红出现在活跃轮 3px 左缘、运行中 chip、编年史右端「高出半格」的当前格、发送键、头像方块——红不做面，只做落位标记。
- 深渊 = 冷青被压成发丝级铅注：思考块只有 1px 左缘 + 7% 冷底 + mono 标签，「向深处探」是版边的批注，不是第二个信号。
- 沉积 = 灰阶里褪色的一档：opacity .55 + birth 灰左缘，颜色退回纸里，不位移。

③ **rep 处理**：换色，珊瑚 → 信号红（C8102E，Pantone 186 系，色阶 E8837A/DA4A3C/C8102E/9E0C24，暗态提明度保可读）。理由：种子要求「agent 只占一个红色信号位」——瑞士语法里暖色的合法性来自它是版面唯一信号，珊瑚的柔与「信号」语义相悖；红与深渊冷青互为光谱两极，比珊瑚更撑得起「唯一」二字。仍守暖=驱力、无换色控件、用户气泡不染 rep。

④ **戒律自检**
1. 拒绝 dashboard ✓ 无数字展览；编年史做成印刷测控条，只标「05 — 08」月份刻度，ctx 环无数字。
2. 品牌水印化 ✓ 左下 opacity .25 + 6s 呼吸；主体是 34px 名片与对话。
3. rep 只属于 agent ✓ 用户气泡暖灰、正文黑、思考块冷青；全屏无第二个暖色源。
4. 整屋空气染色 ✓ `--air` 3.5% 全窗 + 顶部红晕 + speaking 升 5.5%——像信号红被网格中和后的余温。**张力裁决**：瑞士语法本是黑白灰，整屋染色=让空气带一点信号的余温，而非给网格上色。
5. 三要素互斥 ✓ 暖红=正在做、冷青发丝=探深处、灰=旧，语义见②。
6. 暖灰基底 ✓ 亮 #F4F3F0 / 暗 #181612，网格线是暖灰阶不是纯白纯黑。
7. 字体三系 ✓ 水印 Fraunces 兜底栈（Noto Serif SC，离线）/ 正文 Noto Sans SC 400 / 元数据 JetBrains Mono；名片名字用 grotesk 栈是风格本身的字体对比语言（34px 对 10px），属极端对比的执行而非越系。
8. 沉降式动效 ✓ 呼吸 6s 只给 logo 水印、头像方块、banner 呼吸点；呼吸曲线向下收（scale .965），不向上弹；无 spinner/弹跳。
9. 诗意<功能 ✓ 对位十字 opacity .55、栏网格 4.5% alpha 压在内容层下；对话与操控台是绝对主体。
10. 反 AI 味 ✓ 无 emoji/毛玻璃/紫蓝渐变；全屏零 box-shadow，层次只靠发丝线与底色；红是印刷信号红非霓虹。

⑤ **最大的一注**：把 agent 压缩成一个红色方块头像 + 几处同色标记，其余全部交给黑白灰网格——押的是「稀缺即存在」：整个 860px 里只有一个信号源，它比任何晕染都更不可忽视；若败，界面会被读成「一份排版稿，agent 只是页边批注」，个体性输给版面。
