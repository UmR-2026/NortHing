## 九、关键设计约束提醒

1. **Slint 平台限制**: 无 box-shadow（用 drop-shadow）、无 color-mix（用预计算 hex）、无 ellipse 渐变（用 circle）、无 ::before/::after（用显式 div）
2. **诗意 < 功能**: 工作是视觉主体，agent 内在表达克制
3. **品牌与个体分离**: northing logo 仅角落水印（opacity 0.25），agent 名片是视觉主体
4. **两态设计**: 收起态（860px，8px 把手）/ 展开态（1280px，28px 把手 + 280px 抽屉）
5. **沉降式动效**: 慢、重、向下。呼吸只给 logo + agent 头像。禁止弹跳/spinner
6. **同源色绑定**: 界面强调色 ≡ 渐变条右端（当前代表色）
7. **Session banner**: 在对话流内（非顶栏），左=session ID 可折叠 / 右=归档
8. **窗口变宽**: 点击把手 → 窗口物理变宽（非遮罩叠加），Slint 用 `set_inner_size()`
