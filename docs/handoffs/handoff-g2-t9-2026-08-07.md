## What T9 ships

A new periodic judge-mom sweep — `run_competition_review(workspace_root)` in
`src/crates/assembly/core/src/service/agent_memory/competition_review.rs` — that opens the
memory DB, gates on a 24h cadence key in `judge_mom`, loads the top 20 keyword weights, asks an
in-process LLM to propose competition relations or rollbacks, accumulates evidence per workspace
through `judge_mom` KV under `competition_pending:<workspace_root>`, and applies confirmed
relations through the shipped T8 `CompetitionGroupStore` port. Confirmed groups are global (no
workspace column); rollback deletes the group via full-replacement save with an empty member list.

Crate-side logic in `src/agentic/src/review/`:

- `propose.rs` — neutral prompt builder + `parse_competition_proposals` (tolerant, whitelist,
  char-based rationale truncation, group-id sanitization) + `record_proposals` pending-state
  machine that emits `ProposeAccepted`, `Confirm`, and `Rollback` decisions; reuses
  `llm_output::strip_json_fence` and `verdict::MAX_REASON_CHARS`.
- `route.rs` — pure `plan_confirmation` planner that removes confirmed members from every other
  group, dissolves groups with `<2` remaining members, and renormalizes shrunk groups over their
  existing shares. Preserves `created_at_ms` of pre-existing rows. No IO.

Audit rows use the convention `fact_id = "competition:<group_id>"` (documented in
`competition_review.rs:3-5`) because `fact_reviews.fact_id` is `NOT NULL`; reviewer
`"judge-mom"`, actions `propose_competition` / `confirm_competition` / `rollback_competition`.

## User decisions baked in

1. **Cross-group convergence = forced single membership at confirm time.** A confirm removes its
   members from every other pre-existing group; groups reduced below 2 members are dissolved.
   The T8 write-side first-group defense and read-side max-share defense stay in place as
   unreachable-in-steady-state guards.
2. **Evidence accumulates per workspace; confirmed groups take effect globally.** Pending
   evidence is keyed under `judge_mom` KV (`competition_pending:<workspace_root>`); confirmed
   groups have no `workspace_key` column. This is a documented relaxation of D7's "same
   workspace" wording — the underlying global behavior was already shipped in T8 and reviewed.
3. **Rollback is single-shot (no evidence threshold).** Removing a group is the safe direction
   (suppression lifted, no data destroyed). The audit row still records it as
   `rollback_competition`.

### Gemini model drift and the send rule

`session.send` without an explicit `model` field silently uses the session's default. In this
environment the default drifts to `google/antigravity-gemini-3.1-pro`, which is what T9
unintentionally ran on. The fix is `session.send` with an explicit `model` field. If you want
to continue T9 work on the same session, send `model: "google/antigravity-gemini-3.1-pro"`
every time, otherwise the session will resume on whatever model it last picked.
