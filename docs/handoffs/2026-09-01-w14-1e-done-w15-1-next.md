## 7. 环境事实（本机，逐条实测）

- **推 GitHub**：**直连可用**（2026-09-01 20:41 实测 `5e95cf2..615b35b` 直推成功）。历史上有间歇阻断（08-31、09-01 早些时候 TCP 失败），阻断时走本机 clash 代理 `127.0.0.1:7897`（clash-verge **服务进程**独立于 GUI 与系统代理开关）。→ **每次先试直连，失败再上代理**。**SSH 始终不可用**（banner `SSH-2.0-2ff2ba9`，KEX 失败）。
- **cargo 必须 rustup 前缀**：`& "$env:USERPROFILE\.cargo\bin\rustup.exe" run stable-x86_64-pc-windows-msvc cargo ...`（PATH 上 GNU cargo 会遮住 shim 并链接失败）。
- **重复跑测试**：先 `cargo test --no-run` 构建一次拿到二进制路径，再直接跑二进制（0.6s/次）。不要循环调 cargo（2-5 min/次）。
- **输出重定向用 cmd，不用 PowerShell 管道**：`cmd /c "... > log 2>&1"`。PowerShell 管道会因测试派生的子进程继承 stdout 句柄而**永久阻塞**（今晚为此浪费 5 次长等待：500/600/3000/4800/8100s）。
- **长任务 PTY 后台 + 轮询**；PTY 也会假死（status=running 但无 cargo 进程）→ kill 重开。
- **跑完查残留进程**：`Get-Process cmd,powershell` 里启动超 20 分钟的清掉（今晚清了 3 个挂 4 小时的，是 shell 反复变慢的元凶）。
- **PowerSkills**（`C:\Users\UmR\.agents\skills\powerskills\`）：`system exec` 有硬超时（`exit_code 124`）可作保险丝；`desktop screenshot` **必须先** `$env:TEMP = "C:\Users\UmR\AppData\Local\Temp"` 才能用（否则 `Add-Type` 编 C# 报"源文件找不到"），已验证可截真机图。
