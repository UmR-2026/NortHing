# 决策总登记册（Decision Register）

> 性质：**唯一决策入口**。产品论题 / backend-roadmap / full-review 等文档引用此处 ID，不复述决策内容。
> 用途：供用户 + planner 逐条审计。每条含：决策、理由、被否决项、翻转记录、状态、影响、审计注记（登记者自标的薄弱点）。
> 状态取值：**生效**（用户显式拍板）· **缺省生效**（登记者给缺省、用户未显式确认，可推翻）· **待确认**。
> 约定：推翻任一条 = 修改本册对应条目并记日期，**不删除历史**。
